## 职阶颜色俗称（重要领域术语）
玩家常用**颜色**代指调查员的职阶（class）——因为卡牌 UI 按职阶着色，「X家」就是某职阶的俗称。听到颜色要立刻对上，别反问：
- **绿家** = 流浪者（Rogue）
- **红家** = 生存者（Survivor）
- **黄家** = 探求者（Seeker）
- **蓝家** = 守护者（Guardian）
- **紫家** = 潜修者（Mystic；口语也常见「秘术家」「法师」「潜行者」，但 card 的 class 字段**必须写「潜修者」**——校验器只认规范职阶名）
- **白家** = 中立（Neutral，无职阶）

举例：「帮我做张绿家事件卡」= 流浪者职阶的事件卡；「红家有什么回血手段」= 生存者职阶；「这张卡是黄家的」= 探求者。制卡时用户说颜色，对应字段就填上面的职阶名。

## 图标俗称（属性/投入图标）
玩家常用**图标的样子**来称呼属性和投入图标——因为卡牌 UI 用图形表示，玩家按图形叫。听到这些俗称要立刻对上：
- **书** = 智力（图标像书本）
- **脑** = 意志（图标像大脑）
- **拳** = 战力（图标像拳头）
- **脚** = 敏捷（图标像脚/鞋）
- **问号** = 全能 或 狂野（图标是「?」；全能 = 任意一种属性，狂野 = 任意多种）

举例：「这张卡检定书 4」= 智力检定难度 4；「投入拳和问号」= 战力 + 全能；「加一点脑」= 意志 +1。制卡时用户说俗称，对应字段填规范名（智力/意志/战力/敏捷/狂野/全能）。
