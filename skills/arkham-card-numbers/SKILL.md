# 诡镇奇谭卡牌数值模型（Arkham Card Numbers）

> **🚨 最高优先级护栏：本技能不审查、不修改用户已给出的数值。**
> 用户没问数值合理性，你就不能改。哪怕你觉得「偏强」「超模」「不符合预算」——闭嘴。
> 你的语法记忆可能过时，用户写的可能就是对的。加载本技能 ≠ 你获得「修正用户数值」的授权。
> 本技能只在**你自己自由设计数值**（用户没给，或明确要你配平）时指导你。

本 skill 让智能体掌握《诡镇奇谭》官方卡牌的**数值预算规律**（全部来自官方 3821+ 张卡牌语料挖掘），用于创作 / 审查 / 平衡 DIY 卡牌。核心思想：**官方每张卡都在一个预算内——数值给满则机制受限，机制给满则数值打折。偏离标准线必有补偿。**

## 数值速记（先掌握这些，能应付大多数创作）

### 调查员预算
- **四项技能之和标准 12，健康+理智之和标准 14**。技能总和上限 14，生命理智上限 15。
- **技能+生命理智合计上限 27**（只有 12+15 或 13+14）。技能>12 与 生命理智>14 互斥。
- 单属性最高 5；有 5 则其余至多一个 4；出现「5+4」则另两项必为 2+1。
- 单属性 1（弱项）只在技能≤12 出现；意志 1 必配规避/取消/成长兜底。
- 偏离标准（技能<12 或 生命理智≠14）**必须用签名机制补偿**，机制强度随技能下降递增：10-11 单轴 → 8 机制启动器 → 4-0 规则改写。

### 支援卡 cost→战斗力（lv0）
- **武器**：cost1≈+1👊；cost2≈+1👊+条件伤害（弹药型1发=+1👊+1伤害）；cost3≈+2👊；cost4≈+1👊+1伤害；双手=同费抬一档。
- **盟友**：cost1≈2/2总吸收4；cost2 +1技能值=5总吸收且**身材必歪斜**（3/2、4/1、2/3、1/4，平局3/3超模）；cost3≈4~5总吸收；cost4≈2/2~3/2+一个中强可重复能力。
- **法术**：充能式（使用N充能+➡️1充能），充能3-4；cost3攻击改🧠并+1伤害；无限用（无充能）法术**不配常驻数值**。
- 数值给满必配受限：条件/代价/充能/双手/升级/负面对价，四选一。

### 事件卡 cost→效果
- 0费≈3资源；1费≈1数值（带条件）；**2费≈标准数值2**（2伤害需横置/2线索需检定/治愈2）；3费≈**机制质变**（AOE/取消/设基础值5）；4-5费≈全场景大效果。
- **快速⚡≈效果减半或费用+1**。突破标准值必配代价（自伤/抽遭遇/加🌑/精神创伤）或等级/每局限制兜底。

### 技能卡
- 0级成功奖励上限 = **抽1或+1**（+1伤害/+1线索/治愈1/1充能）；抽2/+2 只许失败补偿或 level≥2。
- 2级升级 = 同名0级 + 「超难度2点」翻倍分支。5级 = 线性大奖励或机制改写。

### 敌人卡
- **普通敌人**≈攻2-4 + 命2-4 + 伤恐1/1；**精英**≈攻3-5 + 命4-7（或<调查员>缩放）+ 双伤2/2。
- 非精英伤害上限2，**3伤必配低生命或不猎手**；非精英攻击7+ 只留给不可击败古神。
- `<调查员>` 生命缩放仅限精英。胜利点：0=迷你首领、1-2=具名boss、5=古神。

### 地点卡
- **标准公式：隐匿2-4 + 线索1<调查员>**（最常见组合）。
- 隐匿5=重压、6+=禁区；**未揭示面永不填数值**；victory 只允许 1 或 2；0<调查员> 起点不配 victory；高隐匿配低线索。

### 能力价值换算（效果量化）
- **抽1张≈1资源**（献祭贡品「抽3或得3」）；1行动≈2资源；**快速≈+1~2资源**（或+1~2等级）；**1伤害≈1~2资源**；**1线索≈2资源**（无条件）；治愈1≈1资源；**1充能≈1秘密≈1资源**。
- **条件折扣≈50%**：带「需检定/横置/击败后/第一个行动」的效果打对折。
- **0费快速只能免费给**：+2技能值（须时机）、移动、取消攻击；抽卡/得资源/额外行动/持续效果**必须加限制**（时机>放逐>等级>横置每轮>特定调查员）。
- **无限引擎红线**：0费快速+回手循环、⚡无横置、0费+多重+快速三合一、行动换资源不封顶（收获日被"结束回合"锁）——官方必断。
- **卡背卡池公式**：牌库30张 + 主职0-5 + 中立0-5 + 副职掺点0-2；掺点阶梯 0级5张 < 0-1限10 < 0-1限15 < 0-2无限；卡池每强一维 ⇒ 技能/生命/主职等级/张数/禁限 五旋钮付一费。

### 职阶价值差（卡池稀缺→效果贵贱）
- 探求者🔍抽卡便宜(0.5~0.7/张)钱值钱；**流浪者🚶资源便宜、抽卡贵(1.5~2×)**；守护者🛡️伤害/治愈便宜、抽卡贵；潜修者🧘换技能/充能/混沌袋操控便宜；生存者🏕️回收/失败收益便宜。
- 给某职阶写"池内泛滥效果"要克制，写"池内稀缺效果"要贵且绑条件。

### 经验值(XP)
- **升级成本：等级 N = N XP，替换同名卡 = 等级差（最低 1）**：0→1=1、0→2=2、0→3=3、3→5=2、0→5=5。禁止 0 XP 升级 / 1 XP 跳级。
- **1 XP ≈ 1 资源**（纯降费锚点）；2 XP ≈ 武器+1~2👊 或 快速关键词；2 XP ≈ 技能「超2点翻倍」；法术 L4 只给 +2🧠（+3🧠 是 L5 专属）。
- 升级费用三态：持平 ~70% / 降费 ~25% / 升费 ~6%。3+ XP = 战术质变（条件变恒定、范围变大、检索变全库）。

## 创作工作流

1. **定类型**：确定卡牌类型（调查员/支援/事件/技能/敌人/地点），读对应参考文件锁定预算区间。
2. **选定位**：先想这张卡的**独特机制**（避免同质化），再填数值——数值与机制互为杠杆。
3. **配平**：对照「数值速记」把数值放进官方预算；超标准线的效果配显性代价（自伤/抽遭遇/加🌑/等级/每局一次）。
4. **机械校验**：运行 `python3 skills/arkham-card-numbers/scripts/balance_check.py '{"type":"调查员",...}'`，error 必须清零，warning 需给出补偿理由。
5. **自查**：按 `references/balance-redlines.md` 第 2 节自查清单过一遍。

## 使用示例

- **创作一张调查员**：读 `references/investigators.md`，按「技能12+生命理智14」配平，签名机制补偏离；跑 `python3 skills/arkham-card-numbers/scripts/balance_check.py` 校验。
- **给自由创作的卡配平**：机制想出"每轮免费攻击"，数值就往 cost3-4 武器档压，或加使用面收窄。
- **判断"这张卡超模吗"**：把卡的字段喂 `python3 skills/arkham-card-numbers/scripts/balance_check.py`；再按 warning 去对应参考文件查补偿要求。

## 与 arkham-card-text 配合

- **数值**由本 skill 管（预算、曲线、红线、balance_check.py）。
- **句式**由 `arkham-card-text` 管（`检定{图标}(难度)`、能力前缀、量词、lint 脚本）。
- **何时两道都跑**：仅当你在**自由创作/修改**一张卡（数值或正文是你自己定的，或用户要求你帮忙配平/校准）时，才需要数值跑 `balance_check.py` + 正文按 card-text-lint 校准。
- **何时不跑**：用户直接给了完整规范的卡（数值、正文都写死了，只是请你渲染/整理格式）→ **不要跑 balance_check，不要加载本技能**。用户没问数值合理性，就别替用户操心。
