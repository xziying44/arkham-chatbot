## 1. cost→效果预算分层

| cost | 标准值（直接数值产出） | 例 |
|---|---|---|
| 0 | ≈**3资源**，或快速+2技能值，或抽2-3卡（带条件） | 应急物品、艺高胆大、荒谬的素描像 |
| 1 | 带前置条件的**1数值**（1伤害/1线索/治愈1+抽1）；检定成功可到2 | 深度伤痛、自由表演 |
| 2 | **标准数值2**：2伤害（需横置/未交战/敌人生成）或2线索（需检定成功）或治愈2 | 偷袭、跟踪、紧急救援 |
| 3 | **机制质变**：AOE每敌人2伤害 / 攻击+2伤害 / 快速把单技能基础值设为5 / 大资源10 | 灵力风暴、背刺、百战百胜 |
| 4-5 | **全场景大效果**：炸药爆破全场3伤害、生存意志免揭混乱袋、调虎离山躲避全场敌人 | 炸药爆破、调虎离山 |

- 0-1 费为快速集中区（全部 147 张快速事件中 104 张=71% 在 0-1 费）。
- 低于标准的 2 费卡存在（帮个小忙、最后的枪击=1伤害），属服务/响应型走非数值轴。

## 2. 快速（⚡）溢价

- **快速≈效果减半 或 费用+1**：专业直觉 cost2 快速=1线索 vs 跟踪 cost2 非快速=检定成功2线索。
- 防御/响应/检索/整备类快速卡不适用「减半」。
- 快速2费突破1数值需要极端前置：拨云见日 cost2 快速 2线索 但要求「当前难度须为0」。

## 3. 攻击事件伤害加成

| cost | 伤害加成 |
|---|---|
| 0 | +1（以被敌人攻击为代价） |
| 1 | +1（检定）~ +2（自伤换：鲜血失色受2伤换+2） |
| 2 | +1~+2 |
| 3 | +2~+3（背刺+2、提尔斯哈之牙+3） |

- 加成常与技能值加成捆绑；纯增伤卡在低费同样存在（正面迎击、枪法如神）。
- 耀灿一击（cost1 lv1 封印3🌟→+3技能+3伤害）与照明弹（cost2 lv1 放逐→+3👊+2伤害）是封印/放逐代价突破区间的上探。

## 4. 代价换数值

突破标准值的高数值事件**必配显性代价**，或等级/每局限制兜底：

| 代价类型 | 例 |
|---|---|
| 自伤 | 鲜血失色（受2伤换+2）、恐怖揭露（被击败+精神创伤换3线索） |
| 抽遭遇卡 | 飞蛾扑火（0费抽遭遇换2线索） |
| 加🌑（隐藏值） | 掀起麻烦（加🌑=隐藏值换2线索）、浮士德的交易（加2🌑换5资源） |
| 花行动翻倍 | 刨根问底（2费+行动抽5）、银行劫案（2费+行动8资源）、静候时机（0费+行动+2行动） |
| 等级/每局限制兜底 | 团结一致（L3 双人抽2+2资源）、全身而退（L4）、百战百胜（L4 10资源） |

## 5. 高费用=机制质变

3 费起机制切换为绝对主流，而不是数值线性叠加：AOE（灵力风暴）、取消攻击（催眠术）、全局检定（勇闯火线把技能基础值设为5）、检索（解锢灵魂）。少数 3 费仍为单体数值缩放（背刺+2、我有个计划按线索+1~3）。

## 6. 升级规律

- L2 升级常见「揭示符号→回合末返回手牌」**可重复化**（幽灵利刃、解读秘符、缥缈灵体、破門而入），而非纯堆数值。
- 升级也常见**费用下降**（最坏的打算/恢复元气/英勇救援 cost1→0，坚守信念 cost2→0）。

## 7. 超模红线

- ❌ 0费无条件发现2+线索（官方0费2线索必带代价，3线索=自杀）
- ❌ 1费无条件造成2+伤害（官方1费伤害上限=1点；2点必配检定/混沌袋运气/自伤）
- ❌ 2费无条件3+伤害（官方最高=直击弱点2费3伤害但要求难度0极端条件）
- ❌ 快速+无代价双数值（官方快速2费最多1线索/1伤害；0-2费快速无代价2伤害=越线）

## 8. 避免同质化

- **同费用换不同检定技能+捆绑机制**：2费调查事件用🦶（破门而入+自动躲避）/📚（跟踪）/🧠（解读秘符+忽略地点效果），而非只调数值。
- **用前置触发时机切节奏**：同一费用区间按「快速时机/击败敌人后/检定失败时/最终密谋在场」分槽。
- **用代价拉出高数值线**：自伤/抽遭遇/加🌑/精神创伤换更高数值，与低代价低数值线并行。
- **服务类用「打出时提升费用」做弹性**：帮个小忙/情报报告让同一张卡在费用内自助选数值。
