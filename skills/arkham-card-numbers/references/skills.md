## 1. 0级成功奖励上限

**0级成功奖励预算固定为：抽1张，或在指定检定类型（攻击/调查/躲避）成功时给 +1伤害/+1线索/治愈1恐惧/1充能。**

- 任何「成功抽2」「攻击+2伤害」「调查+2线索」「治愈2」在 0 级无门槛版**不存在**——它们要么挂在失败触发（重拾信念），要么是 level≥2（致命打击2/推理2/无所畏惧2）。
- 0级非标准奖励（思维敏捷超2点→额外行动、净化每超1点加🌟）都不突破抽1/+1量级上限。

## 2. 升级公式

同名 0→2 升级有几种路径（不是固定一条）：

| 路径 | 例 |
|---|---|
| **基础效果 + 超难度2点翻倍**（旗舰模板） | 致命打击 +1→+2伤害、推理 1→2线索、无所畏惧 治愈1→2 |
| 降门槛 | 机会主义者 超3点→超2点 |
| 扩范围 | 逆反 忽略1符号→忽略全部4符号 |
| 追加新奖励 | 领导力 追加成功双方各2资源 |
| 从纯条件补数值 | 随机应变 0级无奖励→3级+X❓最多3 |

## 3. 1级动态图标

1级「专家/熟练」系允许图标数量**动态等于调查员属性**：

- 双属性互镜像：获得等于你🦶的📚 + 等于你📚的🦶（地区勘测）；📚↔🧠（密教理论）、🦶↔👊（防御姿态）。
- 取最低技能值（行业专家）、按职阶数（人多力量大）。
- 并行路线：基础行动强化（蛮力/迅速撤退/目力敏锐 = 该行动期间2个同色图标+超2点分支）。

## 4. 条件图标阈值档

0级「两档阈值图标」模板：**低档两个不同图标各1（总量2），高档各2（总量4）**。

| 阈值条件 | 低档 | 高档 | 卡 |
|---|---|---|---|
| 手牌≥4/≥7 | 🧠📚 | 🧠🧠📚📚 | 好奇心 |
| 资源≥5/≥10 | 📚🦶 | 📚📚🦶🦶 | 狡猾 |
| 生命+神志≥5/≥10 | 🧠👊 | 🧠🧠👊👊 | 坚定不移 |
| 道具≤2/≤1 | 👊🦶 | 👊👊🦶🦶 | 体格强健 |

- 4 不是 0 级图标上限：放马过来（每交战敌人🧠👊🦶）、力量洪流（每充能🧠❓）可随状态叠加超过 4。

## 5. 额外奖励门槛与失败保险

- **额外奖励统一门槛 = 「成功且超过难度≥2点」**（思维敏捷→额外行动、蛮力→+2伤害）。
- 线性缩放并行路线：净化「每超1点加🌟，最多5」、孤注一掷「每超1点抽1，最多5」。
- **失败保险极**（独立预算）：失败时抽2+2资源（重拾信念）、失败时加2🌟或移除2🌑（既定命运）——体量明显高于成功奖励（抽1），用「只在失败时生效」换更高回报。

## 6. 自动成功成本阶梯

| level | 成本 |
|---|---|
| 0 | 先决触发（揭示🌑）+ 卡牌离场（挚爱） |
| 1 | 投入3张多重（三条A） |
| 2 | 放逐 + 🐙标记仍算失败（鸿运当头） |
| 3 | 加等于难度值的🌑（不择手段） |

没有任何一级自动成功真正无代价。

## 7. 翻倍与5级终点

- **0级翻倍只有两种受控形态**：翻倍「其他投入卡」图标（援助之手，不翻自己）；难度翻倍换结算成功效果两次（赌一把）。
- **5级=终点型设计**：大规模线性奖励或机制改写（真理之眼放逐诡计进胜利区、远古印记封印跳过混沌袋、孤注一掷线性抽5）——DIY 5级若只做+1效果将显著低于官方5级体量。

## 8. 超模红线

- ❌ 0级无门槛「成功抽2」「攻击+2伤害」「调查+2线索」「治愈2」
- ❌ 0级无代价「自动成功」；0级无门槛「额外行动」
- ❌ 0级固定给4+图标或「自身图标无条件翻倍」
- ❌ 0级无代价难度-2（主动出击的难度-2是1级）
