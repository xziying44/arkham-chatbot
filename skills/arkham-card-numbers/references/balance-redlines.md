## 1. 各类型超模红线速查

### 调查员
| 红线 | 官方依据 |
|---|---|
| ❌ 技能总和>14 | 上限14（仅汉克·坚毅） |
| ❌ 健康+理智>15 | 上限15 |
| ❌ 技能+生命理智>27 | 合计上限27（12+15或13+14） |
| ❌ 技能>12 且 生命理智>14 | 双高互斥，官方空集 |
| ❌ 单属性>5；单属性=5 且 生命理智=15 | 15生命者全不带5 |
| ❌ 单属性=1 且 技能总和≥13 | 高技能者全无1弱项 |

### 敌人卡
| 红线 | 官方依据 |
|---|---|
| ❌ 非精英 攻击≥7 且 生命≥7 | 全语料0例 |
| ❌ 非精英 伤害3/3 | 3/3 仅精英/古神+2张具名带弱点 |
| ❌ 非精英 `<调查员>` 生命缩放 | 仅1张具名例外 |
| ⚠️ 非精英 攻击≥7 | 只留给不可击败古神 |
| ⚠️ 可被击败精英 攻击≥7 | 攻击7-8精英全「生命=-」 |

### 地点卡
| 红线 | 官方依据 |
|---|---|
| ❌ 未揭示面带数值 | 680张零例外 |
| ❌ victory>2 | 地点只有1和2 |
| ⚠️ 隐匿≥7 还配线索 | 9张里仅道具间例外 |
| ⚠️ 隐匿≥5 同时线索≥2<调查员> | 需动态降难补偿 |
| ⚠️ 0<调查员> 起点带 victory | 169张仅3例外 |

### 支援卡 / 事件卡 / 技能卡
| 红线 | 官方依据 |
|---|---|
| ❌ cost1 武器常驻+2👊 | 官方最高常驻+1👊 |
| ❌ cost2 单手武器常驻+2👊+1伤害 | 需双手/升级/弹药门控 |
| ❌ cost≤3 每发弹=+3👊+2伤害 | 需 level≥3 且带副作用 |
| ❌ cost2 盟友 3/3 还带+1技能值 | 官方5总吸收且必歪斜 |
| ❌ cost3 盟友 3/3 还带+1👊+1🦶 | 双技能3/3需cost4-5 |
| ❌ cost2 法术配常驻+技能加成 | 法术槽0张「你得到+技能」 |
| ❌ 0费事件无条件2线索/2伤害 | 官方必带代价 |
| ❌ 1费事件无条件2+伤害 | 上限1点 |
| ❌ 2费事件无条件3+伤害 | 无条件3伤不存在 |
| ❌ 0级技能成功抽2/攻击+2伤害 | 0级上限抽1/+1 |
| ❌ 0级无代价自动成功 | 自动成功有成本阶梯 |
| ⚠️ 费用≥8 无降费机制 | 8-10费只给契约/降费事件 |

## 1.5 能力价值红线（0费快速/无限引擎/卡池）

### 能力价值
| 红线 | 官方依据 |
|---|---|
| ❌ 0费无条件>3单位（3资源/3抽） | 官方0费上限=应急物品3资源、素描像条件抽3 |
| ❌ 0费无条件发现线索（1条以上） | 官方0费线索必带代价（恐怖揭露=自杀、掀起麻烦=加🌑） |
| ❌ 1费无条件2+伤害；2费无条件3+伤害 | 无条件2伤需自伤/检定；无条件3伤不存在 |
| ❌ 无条件快速自动成功 | 官方自动成功必绑「难度0」门 |
| ❌ 快速+无条件抽3 | 官方需等级4（隐秘的研究）+只能你回合 |

### 无限引擎（官方必断的闭环）
| 红线 | 官方依据 |
|---|---|
| ❌ 0费快速 + 抽卡 + 自身回手/循环 | 官方0费快速抽3不回手；技能回手被「每检定限1」锁死 |
| ❌ 0费快速 + 得资源 + 能覆盖成本再循环 | 冤大头循环是非快速且被多重张数限死 |
| ❌ 免费触发⚡无横置无消耗 | 切片中每个⚡都配横置或花费（受召猎犬、外勤特工） |
| ❌ 0费 + 多重 + 快速 三合一 | 官方把多重循环与快速拆开，从不合并 |
| ❌ 行动换资源不封顶 | 收获日被「立即结束回合」硬封 |
| ❌ 免费再打 + 无消耗回收闭环 | 官方只靠多重张数上限或放逐/移除游戏断链 |

### 卡背卡池
| 红线 | 官方依据 |
|---|---|
| ❌ 双职阶同时0-5 | 官方最宽仅萝拉5职阶全0-3；第二池必被压等级或数量 |
| ❌ 主职0-5+关键词0-5+副职0-2 三池齐开 | 官方多池调查员必在主职等级或数量上限付费 |
| ❌ 独立职阶掺点0-3+ | 官方职阶掺点封顶0-2，0-3只出现在特质池 |
| ❌ 大牌库无代价（50张不加弱点/构造税） | 曼蒂50张必配3张神秘证据；乔40张必配≥11洞察事件 |
| ❌ 反转式放开「主职0级最多5张」 | 官方锁死5张上限 |

### 职阶价值
| 红线 | 官方依据 |
|---|---|
| ❌ 给探求者写「0费无条件抽3+」 | 探求者抽卡本已便宜，再压价即崩（官方0费抽3需L4或加🌑） |
| ❌ 给流浪者写「无条件资源便宜引擎」 | 流浪者0费资源≥4即超模（浮士德0费5资源已带2🌑天花板） |
| ❌ 给潜修者写「换技能/充能/混沌袋操控」还标高价 | 池内泛滥，单点操控官方只卖0~2费 |
| ❌ 给生存者写「无条件大效果0费」 | 生存者0费=大效果+强条件（道路尽头限最终密谋、背水一战限落后） |
| ❌ 给守护者写「免费攻击买断」 | 求生匕首2费挨打免费反击已致伤害交换无限膨胀 |

### 经验值(XP)
| 红线 | 官方依据 |
|---|---|
| ❌ 0 XP 升级 / 免费拿高等级卡 | 官方任何等级差最低 1 XP |
| ❌ 1 XP 跳级（0→3 只花 1 XP） | 官方按等级差计费，升到 N 级必付 N XP |
| ❌ 1 XP 送关键词/免费动作 | 快速、免费攻击官方都要 2 XP |
| ❌ 法术 L4 就给 +3🧠 | 官方 L4 攻击法术统一 +2🧠，+3🧠 是 L5 专属 |
| ❌ 技能 L2 无条件翻倍 | 官方 L2 翻倍必须挂「超难度≥2」门 |
| ❌ 低等级转永久 | 永久集中在 L3~L5（黑马 L5） |

## 2. 数值自查清单

写一张 DIY 卡后，逐项过：

**调查员**
- [ ] 技能总和是否 12？偏离（<12 或 13-14）是否有签名机制补偿？
- [ ] 健康+理智是否 14？偏离是否有补偿？（15→技能≤12；10→超强机制）
- [ ] 单属性是否 ≤5？有 1 弱项是否配了兜底？5+4 型另两项是否 2+1？
- [ ] 弱项弃的是不是战斗/敏捷？（意志1 必须配规避/取消/成长引擎）
- [ ] 技能+生命理智是否 ≤27？

**支援卡**
- [ ] cost 是否符合该费用档的战斗力标准？（cost1→+1👊，cost2→+1👊+条件伤害…）
- [ ] 数值给满时是否配了受限机制？（条件/代价/充能/双手/升级）
- [ ] 盟友身材是否在费用预算内且形状合理？（cost2→5总吸收且歪斜）
- [ ] 充能/弹药总量是否≈费用级？

**事件卡**
- [ ] 效果是否符合 cost 档标准？（0费→3资源，1费→1数值，2费→2数值，3费→质变）
- [ ] 快速是否减半了数值？突破标准是否配了代价/等级兜底？

**技能卡**
- [ ] 0级是否只给抽1/+1？成功奖励是否超量？
- [ ] 升级是否走了官方路径（翻倍/降门槛/扩范围）？

**敌人卡**
- [ ] 非精英是否在 攻2-4/命2-4/伤恐1 区间？越界是否配了补偿？
- [ ] 精英是否在 攻3-5/命4-7/双伤 区间？可被击败则攻击≤6？
- [ ] 3伤是否配了低生命或不猎手？
- [ ] 胜利点是否符合经济（0=迷你首领、1-2=具名、5=古神）？

**地点卡**
- [ ] 已揭示面是否 隐匿2-4/线索1<调查员>？未揭示面是否无任何数值？
- [ ] 高隐匿是否配了低线索？胜利点是否≤2？

**能力价值（所有类型通用）**
- [ ] 每个效果按价值单位算过账？抽1≈1资源、1行动≈2资源、1伤害≈1-2、1线索≈2、治愈1≈1、1充能≈1？
- [ ] 突破标准值的效果是否配了代价（自伤/抽遭遇/加🌑/精神创伤/等级/每局限制/放逐）？
- [ ] 带条件的效果是否按 50% 折扣定价了？
- [ ] 0费快速是否只给了「+2技能/移动/取消攻击」？抽卡/资源/额外行动是否加了限制（时机/放逐/等级/横置）？
- [ ] 有没有形成无限引擎闭环（0费快速+回手循环、⚡无横置、行动换资源不封顶）？

**调查员卡背（卡池）**
- [ ] 是否 30张 + 主职0-5 + 副职0-2 + 中立0-5？偏离是否有旋钮付费（技能/生命/主职等级/张数/禁限）？
- [ ] 掺点是否在官方阶梯内（0级5张 < 0-1限10 < 0-1限15 < 0-2无限）？
- [ ] 大牌库/宽池是否配了弱点/构造税？

**职阶价值**
- [ ] 这张卡属于哪个职阶的池子？该效果在池内是泛滥还是稀缺？
- [ ] 给泛滥效果（探求者抽卡/流浪者资源/潜修者换技能/生存者回收）是否克制了数值？
- [ ] 给稀缺效果（探求者资源/流浪者抽卡/守护者抽卡）是否标了高价或绑了条件？

**经验值(XP)**
- [ ] 升级成本是否按等级差计费（最低 1 XP）？有没有 0 XP 升级 / 1 XP 跳级？
- [ ] 2 XP 是否只给了 +1~2👊 或快速关键词？有没有给太多？
- [ ] 法术 L4 是否只给 +2🧠？技能 L2 翻倍是否挂了「超难度≥2」门？
- [ ] 永久化是否放在 3~5 XP 档？

## 3. 数值预算速查总表

| 对象 | 标准值 |
|---|---|
| 调查员 | 技能12 / 生命理智14 / 合计≤27 |
| 武器 cost1/2/3/4 | +1👊 / +1👊+条件伤害 / +2👊 / +1👊+1伤害 |
| 盟友 cost1/2/3/4 | 2/2 / 歪斜5总吸收 / 4~5总吸收 / 2/2~3/2 |
| 法术 | 充能3-4，cost3攻击+1伤害，升级lv3+2🧠/lv5+3🧠 |
| 事件 0/1/2/3费 | 3资源 / 1数值 / 2数值 / 机制质变 |
| 技能 0级/2级/5级 | 抽1/+1 / 超2点翻倍 / 线性大奖励 |
| 敌人 普通/精英 | 攻2-4命2-4伤恐1 / 攻3-5命4-7双伤 |
| 地点 | 隐匿2-4 线索1<调查员> 胜利≤2 |
| 能力价值 | 抽1≈1资源 行动≈2资源 快速≈+1~2 伤害≈1-2 线索≈2(无条件) 治愈1≈1 充能≈1 |
| 0费快速 | 只给 +2技能/移动/取消；抽卡资源行动必加限制 |
| 卡背卡池 | 30张 主职0-5 副职0-2 中立0-5；掺点阶梯5→10→15→无限 |
| 职阶价值 | 探求者抽卡便宜资源贵 / 流浪者资源便宜抽卡贵 / 守护者伤害治愈便宜 / 潜修者换技能充能便宜 / 生存者回收失败收益便宜 |
| 经验值 | 升级=等级差(最低1)；1XP≈1资源；2XP≈武器+1~2👊或快速；法术L4只给+2🧠；3+XP=质变 |
