# 职阶卡池价值差（参考文件）

> 来源：五职阶卡池挖矿（每职阶约 165-172 张玩家卡）。**同一效果的价值随职阶卡池的稀缺/泛滥而变化**：卡池里某效果泛滥→便宜，稀缺→贵。写 DIY 卡时先想清楚它属于哪个职阶的卡池。

## 1. 职阶价值矩阵

对照基准价（抽1≈1、行动≈2、快速≈+1~2、伤害≈1~2、线索≈2、治愈1≈1、充能≈1）：

| 效果 | 守护者🛡️ | 探求者🔍 | 潜修者🧘 | 流浪者🚶 | 生存者🏕️ |
|---|---|---|---|---|---|
| 抽卡 | **贵**(2~3) | **便宜**(0.5~0.7) | 受限便宜(0.6~1) | **贵**(1.5~2×) | 条件便宜 |
| 资源 | 捆绑(1~2) | **贵**(0.5~1费/个) | 条件便宜(0.5~0.7) | **便宜**(0.5~0.7×) | 中 |
| 伤害 | **便宜**(0.5~1) | 高价稀缺 | 便宜(0.7~1.5) | 基准(1~1.5×) | 中 |
| 线索 | 捆绑(1~2) | **便宜**(0~1) | 持平(2) | 不便宜(1~1.5×) | 便宜(0.5~1) |
| 治愈 | **便宜**(0.5~1) | 高价稀缺 | 便宜(0.5~1) | 贵 | 中 |
| 行动/快速 | 免费攻击便宜 | 基准 | 换技能几乎免费 | **便宜**(0.3~0.5×) | 快速标配48% |
| 该职阶身份 | 武器/治愈/伤害 | 抽卡/线索/书籍 | 换技能/充能/混沌袋 | 金钱/行动/躲避 | 回收/失败收益 |

**一句话**：给 A 职阶写"便宜效果"=复制它的池子（同质化）；给 A 职阶写"贵效果"=跨界进它的池子（要谨慎，因为稀缺所以贵）。

## 2. 守护者🛡️

定位：武器/战斗/治愈/防御。

| 效果 | 价值 | 锚点 |
|---|---|---|
| 伤害 | 便宜 0.5~1/点 | 单打独斗 0费1伤(首行动)、正面迎击 0费自动成功+1伤 |
| 治愈 | 便宜 0.5~1/点 | 恢复元气 0费治愈2~3+抽1、急救 2费3补给每次1点 |
| 武器+👊 | 便宜 0.5~1/+1 | 金属棍棒 1费常驻+1👊、双刃短刀 1费按交战敌数+X👊 |
| 免费反击/免费攻击 | 超便宜 1~2/次 | 求生匕首 2费挨打免费+2👊+1伤害、手眼协调 1费免➡️费用触发 |
| 快速取消攻击 | 便宜 1/次 | 闪躲 1费取消攻击 |
| **抽卡** | **贵 2~3/张** | 抽卡全捆绑交战/受击/失败/高等级，无干净抽1 |
| 线索 | 中等 1~2/个 | 捆绑击杀/检定；无条件引擎外勤特工 4费 |
| 资源 | 1~2/个 | 全捆绑检定成功/击杀/受击，无独立经济 |

**超模红线**：免费攻击买断(求生匕首)+能站住挨打=伤害交换无限膨胀；0费伤害+自动成功(正面迎击)；0费治愈+抽卡组合(恢复元气价值3~4压缩进0费)。

## 3. 探求者🔍

定位：抽卡/线索/书籍/研究。**验证用户观察：探求者抽卡多→钱更值钱。**

| 效果 | 价值 | 锚点 |
|---|---|---|
| **抽卡** | **便宜 0.5~0.7/张** | 批量平铺：荒唐素描像 2费抽3、刨根问底 2费+行动团队抽5 |
| **资源** | **贵 0.5~1费/个** | 资源生成成本≈0.5~1费/个(基准0.33)，**钱对探求者值钱** |
| 线索 | 便宜 边际0~1/个 | 靠调查引擎而非平铺事件；线索↔资源 1:1(研究笔记/水落石出) |
| 检定加成 | 1资源/秘密=1~2技能值 | 高等教育 1资源=+2是红线 |
| 治愈/伤害 | 高价稀缺 | 医学教科书 2费需检定治愈1 |
| 1秘密 | 0.5~1费 | 凄惨传略/超感知 1秘密→+1~2📚 |

**超模红线**：高等教育式"1资源→+2技能值"永久无冷却；0费快速无条件抽3+（抽卡本已便宜再压价即崩）；无条件0~1费2+线索。

## 4. 潜修者🧘

定位：法术/换技能/充能/混沌袋操控。

| 效果 | 价值 | 锚点 |
|---|---|---|
| 换技能(用🧠替代) | 几乎免费 0~0.5/次 | 剑杖 2费攻击+躲避双模式换🧠；0~2费永久支援默认附带 |
| 充能(事件补能) | 便宜 0.2~0.5/充能 | 重新充能 0费期望+2充能；稳态逐行动补能(影之书)则贵≈3/充能 |
| 抽卡 | 受限便宜 0.6~1/张 | 全部限定{法术}或需牺牲（献祭贡品 0费抽3但弃1支援） |
| 资源 | 条件便宜 0.5~0.7/点 | 毁灭/恐惧/袋差→资源（禁忌知识 0费4秘密、大卫·伦费尔德堆毁灭换钱） |
| 伤害 | 便宜 0.7~1.5/点 | 🧠检定事件压价：幽灵利刃 2费对非精英3伤 |
| 治愈 | 便宜 0.5~1/点 | 治愈真言 2费3充能；3级版低至 0.25~0.5/点 |
| +技能值 | 便宜 0.5资源/点 | 猫面具 1贡品=+2、鲜血盟约 1毁灭=+2，燃料走毁灭/贡品 |
| 混沌袋操控 | 超便宜 | 黑暗预言 1费揭示5选1，卡池泛滥单点操控≈0~1费 |

**超模红线**：大卫·伦费尔德可无限堆毁灭换资源；禁忌知识 0费买断4资源仅需恐惧代价；重新充能 0费期望+2充能≈2资源价值卖0费。

## 5. 流浪者🚶

定位：金钱/敏捷/额外行动/躲避。**验证用户观察：流浪者钱多→抽卡更值钱。**

| 效果 | 价值 | 锚点 |
|---|---|---|
| **资源生成** | **便宜 0.5~0.7×基准** | 0费事件=3~6资源（浮士德 0费5资源、收获日每行动1资源） |
| **抽卡** | **贵 1.5~2×基准** | 稳定抽卡最低2费+触发条件；探求者同费抽2~3张。**抽卡是流浪者的稀缺货币** |
| 额外行动 | 便宜 0.3~0.5× | 杀手锏 0费3行动(卓越)、反应灵敏 2费快速1行动 |
| 快速 | 近乎免费附加 | 0~1费事件常见 |
| 线索 | 不便宜 1.0~1.5× | 内部1线索=2~3资源（夜盗：调查不找线索改获3资源） |
| 伤害 | 基准 1~1.5× | 偷袭 2费横置敌2伤害、帮个小忙 2费1伤害 |
| 躲避/逃生 | 便宜 | 逃生通道 2费快速取消攻击、诱敌 2费自动躲避非精英 |

**超模红线**：0费事件资源产出≥4即超模（浮士德0费5资源已是带2🌑天花板）；快速+额外行动低于约1资源/行动即超模；多重连锁0费资源复合（冤大头）。

## 6. 生存者🏕️

定位：回收/失败收益/乱局翻盘。

| 效果 | 价值 | 锚点 |
|---|---|---|
| **回收(弃牌堆回手/打出)** | **最泛滥最便宜 0~1/张** | 搜刮补给 0费回收、急中生智 技能检定成功回收任意🏕️卡、临时武器 1费从弃牌堆打出还+1伤害 |
| 失败触发收益 | 半价~免费 | 重拾信念 失败抽2+2资源；「看看我发现了什么」2费失败2线索 |
| 无条件抽卡 | 贵(机会价≈2资源/张) | 全绑条件：险中求胜+2难度税、拉布兰奇夫人空手 |
| 线索 | 便宜 0.5~1/个 | 阅后即焚 1费2线索、拨云见日 2费2线索(难度0) |
| 快速 | 标配 48%事件带 | 直击弱点、吉人天相、学无止境——保命/翻盘关键事件几乎全快速 |

**超模红线**：无条件大效果0费卡（官方0费=大效果+强条件，如道路尽头限最终密谋、背水一战限落后）；无条件抽卡便宜（生存者抽卡必须绑失败/空手/落后条件）。

## 7. 中立/多职阶

- **中立 = 全池基准锚点**：通用件按基准表平价定价（应急物品 0费3资源、刀子 1费+1👊、手电筒 2费3次-2隐匿）。中立卡不享受职阶折扣。
- **多职阶泛用折价 25~50%**：跨职阶工具因泛用打折——移动≈0.5~1/次（追踪 1费2移动、远古海图 1秘密=1行动）、充能→线索/伤害/行动 1:1（占卜/克图格亚的烙印/身形虚化），靠"成功且等于难度"反噬平衡。
- **中立抽卡无折扣**：1资源/张且需检定成功触发；免费抽卡只能以特质绑定(背包找道具)或专属形式存在。
- **槽位经济**：额外槽位≈3经验/槽（永久件）；2费支援给2限定槽但占槽可被弃。

## 8. 按职阶写卡的锚点

写一张卡前，先回答：**它属于哪个职阶的池子？这个效果在这个池子是泛滥还是稀缺？**

- 给**守护者**写伤害/治愈/武器 → 池内便宜，数值要给得克制，靠机制/免费触发差异化。
- 给**守护者**写抽卡 → 池内稀缺，2~3资源/张，必须捆绑代价。
- 给**探求者**写抽卡/线索 → 池内便宜，别再做"2费抽3/调查成功额外线索"（做滥了）。
- 给**探求者**写资源 → 池内稀缺，钱对探求者值钱，资源生成要贵/要条件。
- 给**潜修者**写换技能/充能/混沌袋 → 池内泛滥，别只堆数值，靠袋互动/燃料取舍差异化。
- 给**流浪者**写资源/额外行动 → 池内便宜，克制；写**抽卡** → 池内稀缺，贵且绑条件。
- 给**生存者**写回收/失败收益 → 池内泛滥便宜；写**无条件抽卡** → 必须绑失败/空手/落后。
- 给**中立**写通用件 → 按基准表平价，不享职阶折扣；跨职阶工具按 25~50% 折价并配反噬。
