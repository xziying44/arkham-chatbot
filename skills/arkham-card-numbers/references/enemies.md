## 1. 非精英标准曲线

| 数值 | 标准区间 | 占比 | 说明 |
|---|---|---|---|
| 战斗值(attack) | **2-4** | 83% | 1=杂鱼；5-6=上探区间（20张） |
| 生命 | **2-4** | 73% | |
| 伤害/恐惧 | **1/1** | 最多 | 单伤1(143张)、单恐1(135张) |

- 杂鱼：攻击1/生命1/伤害恐惧1（同志会特工）。
- 非精英上探（攻击5-7，共20张）多数靠低血/具名+胜利点/攻击限制补偿，但非必须（盲目舞者6攻5血、原生质团6攻4血均带猎手）。

## 2. 精英升级曲线

| 数值 | 标准区间 | 说明 |
|---|---|---|
| 战斗值 | **3-5** | 76.5% 集中 |
| 生命 | **4-7** 或 `<调查员>` 缩放 | 生命3也常见（39张） |
| 伤害/恐惧 | **2/2** 双伤是精英标记 | 25张 vs 非精英8张 |

- **`<调查员>` 生命缩放近乎精英专属**（48张中47张精英，唯一非精英例外是具名boss暗红骑士·誓约勇士）。DIY 非精英禁用。
- 精英数值分配灵活但总量更高：高速杀手型（石丸春子6攻4血）、肉盾型（乔丹·佩里2攻8血）。
- 可被击败精英最高战斗值6；攻击7-8 的精英（达贡/海德拉/羽翼蛇族）**全部「生命=-」不可击败**。

## 3. 伤害/恐惧组合

| 组合 | 定位 | 例 |
|---|---|---|
| 1/1 | 基底（153张） | 幽灵乌鸦 |
| 2/2 | 精英双威胁标记 | 阿特拉克·纳克亚 |
| 2/None、None/2 | 纯伤战士 / 纯恐灵怪 | 用于错开威胁 |
| 3/3 | **古神级**（全语料仅7张） | 伊格、拟态克星、阿撒托斯 |

- 非精英单值伤害/恐惧上限 2；**3伤必配低生命(≤2)、不猎手或具名补偿**（非精英3伤仅7张）。
- 非精英 3/3 只有 2 张且都带攻击限制型弱点（疯人院暴食怪、畸形骸骨）。

## 4. 躲避值是独立维度

- 主流躲避值 2-3（151/232）。
- **高躲避(5) = 滑溜型**：非精英躲避5仅7张，**生命全部≤4**，配低攻。
- 对称：高血莽撞型用低躲避（1-2）平衡（深潜者巨怪2躲避5血）。

## 5. 胜利点经济

| 胜利点 | 定位 | 说明 |
|---|---|---|
| 无 | 常规遭遇怪 | 非精英177 + 精英56 张 |
| 0（精英） | 迷你首领 | 满配但不给分（38张），强弱混合 |
| 1（非精英） | 具名迷你首领 | 50张，但其中仅18张为具名，其余是普通遭遇怪 |
| 2 | 主 boss 级 | 非精英唯一=深渊吞噬者；精英28张 |
| 5 | 古神/最终boss | 全语料唯一=伊格 |

- 具名迷你首领（非精英 victory=1）≈ 攻击3-6 + 生命3-6 + 胜利点1。

## 6. 超模红线

- ❌ 非精英同时**攻击≥7 且 生命≥7**（全语料 0 例）
- ❌ 非精英伤害 **3/3** 双高（全语料仅7张，全是精英/古神+2张具名带弱点）
- ❌ 非精英使用 `<调查员>` 生命缩放（仅1张具名例外）
- ⚠️ 非精英攻击≥7（只留给不可击败古神）；可被击败精英攻击≥7

## 7. 避免同质化

- **用躲避值错开定位**：同攻击区间，滑溜型高躲避(5)+低血，莽撞型低躲避(1-2)+高血。
- **用伤害/恐惧组合错开威胁**：1/1杂鱼 vs 纯伤2/None vs 纯恐None/2 vs 2/2精英双威胁。
- **用关键词换数值**：攻击+2但失去猎手（水生异怪、原生质团），或低攻换反击/警戒。
- **用生命缩放换个体差异**：大怪用<调查员>缩放，迷你首领用固定高血+具名/弱点。
- **用胜利点经济区分**：victory=0强调"必须处理但不拿分"，victory=1/2 奖励战斗流。
