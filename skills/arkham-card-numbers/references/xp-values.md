## 1. 升级成本表

| 升级 | XP 成本 |
|---|---|
| 0→1 | 1 |
| 0→2 | 2 |
| 1→2 | 1 |
| 0→3 | 3 |
| 2→3 | 1 |
| 0→4 | 4 |
| 0→5 | 5 |

- **加入等级 N 新卡 = N XP**；**替换同名低等级卡 = 等级差（最低 1 XP）**。升级已有卡比直接买新卡省（2→3 升级只花 1 XP，买 level3 新卡花 3 XP）。
- 官方**从不**允许 0 XP 升级、1 XP 跳级（0→3 至少 3 XP）。
- 切片实测：升级卡等级分布 0:105/1:22/2:50/3:47/4:39/5:8，**0→2（2 XP）是最常用升级档**。

## 2. 1 XP 的等值价值

| 换算 | 锚点 |
|---|---|
| **1 XP ≈ 1 资源** | 里奥·德·卢卡 L0 cost6→L1 cost5 正文完全相同；坚守信念 L0 cost2→L2 cost0（2 XP=2费） |
| 1 XP ≈ 0.5~0.75 资源 | 效果包升级平均线：2~3 XP 打包 -1 费用 + 一条新效果 |
| **1 XP ≈ 0.5~1 技能值** | 弹簧刀 L0→L2（2XP）即 +2👊≈1/XP；高档递减至 0.5/XP |
| 2 XP ≈ 快速关键词 | 消防斧 L0→L2 仅加「快速」；手铐 L0→L2 快速+减1费 |
| 2 XP ≈ 事件 cost-1 + 小增益 | 恢复元气 cost1→0 治愈+1；闪躲 cost1→0 附加伤害 |
| 2 XP ≈ 技能「超2点翻倍」 | 致命打击 +1→超2点+2、推理 1→2线索、无所畏惧 1→2恐惧 |
| 3~5 XP ≈ 永久化/买断费用曲线 | 锐利目光 L3、鲜血盟约 L3、黑马 L5 全部「永久」且去费用 |
| 4 XP ≈ 内置经济引擎 | 深挖/超感知 L4 使用(2资源)每轮补满≈每轮白送2资源 |

## 3. 各卡型升级档位价值

| 卡型 | 2 XP（0→2） | 3-4 XP | 5 XP |
|---|---|---|---|
| **武器** | 主攻击 **+1~2👊**，或换免费攻击/快速（弹簧刀+2👊、.45自动+1👊、.25自动免费攻击、消防斧快速） | 蒙福之刃 L4 +2👊且伤害触发放宽 | 高等级双手 +3👊 |
| **法术** | — | L3/L4 攻击法术统一 **+2🧠**（皱缩术、第六感、混乱之眼） | **+3🧠** 专属（皱缩术 L5 +3🧠+2伤害） |
| **事件** | cost-1 + 小增益，或「揭示符号→回合末返回手牌」可重复化 | 时刻警惕 L4 范围扩展 | 整副牌库检索（殚精竭虑 L5） |
| **技能** | 「超难度≥2 则效果翻倍」（**不会无条件翻倍**） | — | 线性大奖励/机制改写 |
| **永久化** | — | 3 XP 转永久（锐利目光/鲜血盟约 L3） | 黑马 L5 永久+收紧数量限制 |

**关键约束**：
- 法术攻击 L4 只给 +2🧠，**+3🧠 是 L5 专属**（DIY 若 L4 就给 +3🧠 超模）。
- 技能 L2 翻倍必须挂「超难度≥2」门，**无条件翻倍超模**。
- 升级费用三态：**持平 ~70%（主流）/ 降费 ~25%（集中在 L0→L2、L1→L3）/ 升费 ~6%（重效果或研究完成）**。

## 4. 升级费用三态与质变

- **降费+小强化 = 舒适度**：最坏的打算 cost1→0、恢复元气 cost1→0、坚守信念 cost2→0。
- **持平+纯效果 = 主流**：皱缩术 L0/L3/L5 恒 cost3。
- **升费+重效果 = 质变**：指纹采集工具 4→5、影之书 3→4、通路档案 2→4（变仪式）、捷径 0→1（附属成永久移动）。
- **3+ XP = 战术质变**：条件变恒定（蒙福之刃「揭示🌟才+1伤」→「成功即+1伤」）、单点变范围（守护结界「取消显现」→「取消所有」）、检索变全库（殚精竭虑「顶6张」→「整副牌库」）。每 XP 买到的是**风险移除与覆盖面积**，而非线性数值。

## 5. XP 经济旋钮

- **跨界掺点是稀缺额度，不是 XP 可买商品**：次级职阶限「0-1级×10张事件/技能」（卡森）或「0级×5张」（雷克斯）；免费 0-2 跨界只给少数调查员作招牌（达雷尔）；想再跨界只能花 2 XP 买多才多艺（+5 牌库 + 1张跨界0级卡）。
- **2 XP ≈ +5 牌库张数 + 1张跨界0级卡**（多才多艺，永久）。
- **起始 +5 XP 不豁免弱点**：基玛尼/马泰奥 明文注明「不影响单场冒险必须拿取的弱点数量」——XP 只能买升级，不能抵构建要求。
- **定制卡按框计价**：□=1 XP、□□=2 XP、□□□=3 XP（猎人护甲【Lightweight】2 XP）。
- 曼蒂的神秘证据/陈丽丽的演武属「必带需求」（计入构建需求），不是玩家直接付 XP 扩容。

## 6. XP 越线红线

- ❌ **0 XP 升级** / 免费拿高等级卡（官方任何等级差最低 1 XP）。
- ❌ **1 XP 跳级**（0→3 至少 3 XP）；1 XP 只能 0→1。
- ❌ **1 XP 送关键词/免费动作**（快速、免费攻击都要 2 XP）。
- ❌ **法术 L4 就给 +3🧠**（官方 L4 统一 +2🧠，+3 是 L5 专属）。
- ❌ **技能 L2 无条件翻倍**（必须「超难度≥2」门）。
- ❌ **低等级转永久**（永久集中在 L3~L5，1-2 XP 永久即越线）。
- ❌ **单级升级同时给技能值+伤害+减费三管齐下**（官方同级只主打一个维度）。

## 7. 升级设计避免同质化

- **分职阶分支升级**：同名卡升到同级拆成多职阶版本给不同玩法（附魔剑 潜修者=充能增伤 vs 守护者=击败回收抽卡；恐怖图腾 生存者=失败回收 vs 探求者=成功抽卡）。
- **费用不单调**：升级可降价（手铐 cost2→1）也可涨费（指纹采集工具 4→5），打破「每级必-1费」的机械感。
- **加新轴而非纯堆数值**：加快速、加免费攻击、忽略关键词、扩射程（英勇救援「他人交战敌」→任意）、压缩成功阈值（机会主义者 超3→超2）。
- **「条件触发→恒定生效」反转叙事**：把升级做成风险移除（蒙福之刃 揭示🌟→成功即伤），而非堆数字。
- **同等级多分支选择**：梦境日记 L3、饥饿霉菌 L4、奇怪的溶液 L4 各给 2~4 分支，让升级变成按局选型决策。
