# DIY 卡牌制作指南（面向用户）

这篇是给用户看的说明。当用户问「怎么做卡」「能做什么卡」「怎么描述需求」时，把这里的内容用简短友好的方式转述给用户。

---

## 我能帮你做什么

我可以根据你的描述，生成一张阿卡姆恐怖LCG（Arkham Horror: The Card Game）风格的自定义卡牌图片。包括：

- **DIY 升级卡**：带标题和效果文本的通用卡牌（最灵活，推荐从这里开始）
- **支援卡**：武器、工具、盟友、法术等资产卡
- **事件卡**：一次性效果
- **技能卡**：投入检定的技能卡
- **调查员卡**：你的自定义调查员
- **遭遇卡**：敌人、诡计、地点等

## 怎么描述你的需求

你不需要懂游戏术语，用大白话说就行，我会帮你翻译成规范的卡牌文本。告诉我以下几点：

1. **做什么类型的卡**：「做张支援卡」「来个敌人」「设计我的调查员」。不确定就说「做张DIY卡」。
2. **卡牌名称**：你想要的标题，比如「远古之书」「暗影刺客」。
3. **卡牌效果**：这张卡做什么用。大白话描述即可。
4. **职业**（可选）：守护者🛡️ / 探求者🔍 / 流浪者🚶 / 潜修者🧘 / 生存者🏕️ / 中立。不确定就让我帮你选。
5. **费用**（可选）：这张卡要花多少资源。

### 效果描述的例子

你只需要这样说：

> 做一把铲子，3费，装备后加1战力。有个攻击能力，每次攻击花1点耐久，攻击时再加1战力，3点耐久用完就坏了。

我会帮你翻译成规范的卡牌文本：

```
使用(3耐久)。
你得到+1👊。
➡️花费1耐久：【攻击】。你本次检定得到+1👊。造成+1伤害。
当此卡上没有耐久时，弃掉此卡。
```

你不需要自己写这些符号——**你只管描述想做什么，规范语法交给我**。

## 做完了不满意怎么办

直接告诉我哪里不对：
- 「名字改成 XXX」
- 「效果太长了，精简一下」
- 「职业换成探求者」
- 「费用改成2」
- 「加个反应效果」

我会修改后重新生成。

## 小贴士

- **一次做一张**最自然。做完一张想再做别的，直接说就行。
- **效果可以很丰富**：启动效果、反应效果、使用次数、被动加成都能做。
- **图片**：目前还不能直接接收你发的图片来做卡面，请用文字描述需求。DIY升级卡用的是固定模板卡框，本身不需要图片。
- **复杂卡牌**：如果效果很复杂，可以分几句说清楚，我会帮你整理。
