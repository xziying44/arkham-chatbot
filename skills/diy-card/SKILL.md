# DIY 卡牌助手

两种模式：**生成卡图** 和 **纯文本效果编写**。根据用户意图选择。

## 模式判断

| 用户说的 | 走哪个模式 |
|---|---|
| 「帮我做张卡」「生成卡图」「设计一张XX卡」 | **生成卡图**（完整流程） |
| 「帮我写个效果」「这个效果怎么写」「翻译成官方用语」 | **纯文本效果编写**（不生成图，但最后可问是否要生成） |
| 不确定 | 先按纯文本走，写完效果后问「要不要帮你生成卡图？」 |

---

## 模式 A：生成卡图（完整流程）

### Step 1：收集信息

确认用户想要什么卡。必须收集：
- **卡牌类型**：若用户没指定，用 ask_user 问（支援卡/事件卡/技能卡/调查员/敌人/地点/升级卡）
- **名称**（name）
- **正文**（body）：效果描述。**把大白话翻译成规范语法是你的核心工作**——如果用户描述不标准，调 `load_skill("card-text-lint")` 校准
- **职业**（class）：守护者/探求者/流浪者/潜修者/生存者/中立

若用户已给全，直接下一步。不足则用 ask_user 或 send_message 简短地问。

### Step 2：查模板 + 配平数值

1. **读 `references/card-types.md`** 查卡牌类型的字段和 JSON 模板（不要凭记忆写）
2. 自由设计数值时，**调 `load_skill("arkham-card-numbers")`** 按官方预算配平

### Step 3：写 .card + 数值校验

用 write 工具写 JSON 到 `cards/in/000.card`（文件名前3位必须是数字）。
配了数值的建议跑校验：
```bash
python3 skills/arkham-card-numbers/scripts/balance_check.py "$(cat cards/in/000.card)"
```
error 必须清零，warning 需给出补偿理由。

### Step 4：发送文本预览给用户确认（重要！）

**先不要渲染卡图！** 渲染和发送都比较慢（3-10秒），用户等太久会觉得卡住了。
用 send_message 把卡牌信息整理成文本预览发给用户：

```
帮你整理好了，请确认：

**【卡名】**（职阶 · 特性）费用/等级
正文效果（规范语法）
数值（生命/理智/攻击等）

确认无误就帮你生成卡图，要改随时说。
```

等用户回复「可以」「没问题」「确认」后再渲染。用户要改就调整后再次确认。

### Step 5：渲染 + 发送图片

```bash
mkdir -p cards/out
.arkham/bin/arkham-cli render \
  --corpus cards/in \
  --assets .arkham/assets \
  --workspace . \
  --out cards/out
```

- `--workspace .` **必须带**：解析 picture_path 的相对路径
- 输出 `cards/out/000.png`，看 `[OK ]` / `[ERR]` 判断成功
- 用 send_image 发送

## 模式 B：纯文本效果编写

用户只想把大白话描述翻译成官方规范语法，不需要生成卡图。

### Step 1：理解用户意图

用户描述效果（如「3费，装上去后获得+1拳，攻击消耗耐久度，用3次就坏了」）。

### Step 2：校准语法

调 `load_skill("card-text-lint")` 加载语法校准技能，按官方规范重写。

### Step 3：发送规范文本

用 send_message 把校准后的效果发给用户：

```
帮你翻译成官方规范语法：

使用(3耐久)。
你得到+1👊。
➡️花费1耐久：【攻击】。你本次检定得到+1👊。造成+1伤害。
当此卡上没有耐久时，弃掉此卡。

要调整随时说。
```

### Step 4：问是否生成卡图

用户确认效果后，可以问一句：「要不要帮你把这张卡生成卡图？」
用户说要就切到模式 A 的 Step 2 继续。说不要就结束。

## 图标语法速查（两种模式通用）

body 里必须用 emoji，不用尖括号标签：

| 含义 | emoji | | 含义 | emoji |
|---|---|---|---|---|
| 意志 | 🧠 | | 战斗 | 👊 |
| 智识 | 📚 | | 敏捷 | 🦶 |
| 行动 | ➡️ | | 快速/反应 | ⚡ |
| 回合结束 | ⭕ | | 独特 | 🏅 |

常用写法：`得到+2👊`、`造成1点伤害`、`发现1个线索`、`获得2资源`、`【攻击】`、`【调查】`。
被动触发（「在…后」「当…时」）用 ⭕ 反应图标，不要用 ⚡。
完整标签参考见 `references/tag-reference.md`。

## 图片处理

- 升级卡（DIY卡）：不需要图片，用固定模板卡框
- 其它卡类型用用户提供的底图：用户发图片时自动存到 `inbox/`，在 .card 里写 `"picture_path": "inbox/xxx.jpg"`（**不加 @ 前缀**）
- 沙箱断网，无法下载网上图片 URL

## 常见错误提醒

- 调查员卡背的 `class` 必须和正面一致（漏填会用中立卡框）
- 被动触发效果用 ⭕ 不用 ⚡
- 渲染命令必须带 `--workspace .`
- picture_path 不加 `@` 前缀
