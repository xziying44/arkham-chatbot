# 卡牌描述规范参考

本文档基于官方卡牌语料库（154 张标准卡牌）整理，是生成卡牌时的**权威语法参考**。

## 核心原则

这套渲染引擎使用 **emoji 符号 + 方括号【】语法**，不是尖括号 XML 标签。

- ❌ 错误：`<拳>`、`<启动>`、`<反应>`、`<t>武器</t>`
- ✅ 正确：`👊`、`➡️`、`⚡`、`{武器}`

## 二、规范术语（必须用这些词）

### 动作名（方括号包裹）

| 规范写法 | 说明 |
|---|---|
| `【攻击】` | 攻击行动 |
| `【调查】` | 调查行动 |
| `【谈判】` | 谈判行动 |
| `【闪避】` | 闪避行动 |

### 核心动词

| 概念 | 规范写法 | ❌ 避免 |
|---|---|---|
| 造成伤害 | `造成1点伤害`、`造成+1伤害` | 「扣血」「掉血」 |
| 受到恐惧 | `受到1点恐惧` | 「掉恐惧」 |
| 治愈 | `治愈1点伤害`、`治愈1点恐惧` | 「回血」 |
| 弃置卡牌 | `弃掉`（动词）、`弃牌堆` | 「丢弃」「扔掉」 |
| 横置 | `横置`（exhaust） | ❌「消耗」（本游戏不用这个词） |
| 重整 | `重整`（ready） | 「恢复」 |
| 获取资源 | `获得2资源` | 「加钱」「得金币」 |
| 花费资源 | `花费1资源` | 「花钱」「扣资源」 |
| 发现线索 | `发现你所在地点的1个线索` | 「拿线索」 |
| 抽卡 | `抽取1张卡牌` | 「摸牌」 |
| 移动 | `移动到一个连接地点` | 「走去」 |
| 交战 | `与你交战的敌人` | — |
| 从游戏移除 | `从游戏中移除` | 「放逐」 |

### 关键词（首行单独声明）

| 关键词 | 含义 | 用法 |
|---|---|---|
| `快速。` | 快速行动（不消耗行动） | body 首行 |
| `永久。` | 永久卡（不可被弃置） | body 首行 |
| `卓越。` | 卓越卡（独特） | body 首行 |
| `猎手。` | 猎手关键词（敌人） | body 内 |

### 限制次数（圆括号注）

| 写法 | 含义 |
|---|---|
| `(每回合仅限一次)` | 每回合限一次 |
| `(每轮仅限一次)` | 每轮限一次 |
| `(每次检定仅限一次)` | 每次检定限一次 |
| `(每次调查仅限三次)` | 每次调查限三次 |

### 遭遇卡关键词（剧本卡）

写在 body 里用【】包裹，后接 ` - `（空格破折号空格）：

| 写法 | 含义 |
|---|---|
| `【强制】 - 时机：效果` | forced，最高频 |
| `【显现】 - 效果` | reveal，诡计卡专属 |
| `【生成】 - 地点。` | spawn |
| `【猎物】 - 条件` | prey |
| `【目标】 - 描述` | objective |

## 三、富文本标签（少量使用）

语料中 body 实际使用的标签：

### 斜体注解 `<i>...</i>`

用于规则澄清或英文原名：

```
将放在一边的哈斯塔<i>(黄衣之王)</i>敌人放置入场
```

### 选择列表 `<点>`

用于「选择一项」场景，每项一行：

```
以任意顺序依次结算，如果你控制……
<点> 🚶卡牌，你可以移动到一个连接地点。
<点> 🛡️卡牌，对你所在地点的一个敌人造成1点伤害。
<点> 🔍卡牌，发现你所在地点的1个线索。
```

### 特性引用 `{特性名}`

花括号引用特性，渲染为特性图标：

```
非{精英}敌人
一张{枪械}支援
{护甲}、{枪械}或{近战}卡牌
```

## 四、行动效果规范句式（完整示例）

### 启动效果（➡️）

```
➡️[行动成本]：【动作名】。[效果描述]。
```

**示例**（蒙福之刃）：
```
➡️：【攻击】。你本次检定得到+2👊。如果本次攻击成功，造成+1伤害。
```

**示例**（短管霰弹枪，有成本）：
```
➡️花费1子弹：【攻击】。本次攻击不造成标准伤害，改为你检定成功且每超过难度1点，造成1点伤害(最小为1，最大为6)。
```

**示例**（水手的罗盘，需横置）：
```
➡️横置水手的罗盘：【调查】。如果你检定成功且你的资源池中没有资源，发现你所在地点额外1个线索。
```

### 反应效果（⚡）

```
⚡[触发条件]，[行动成本]：[效果描述]。
```

**示例**（好勇斗狠）：
```
⚡在{护甲}、{枪械}或{近战}卡牌上的技能检定期间，从好勇斗狠花费1资源：你本次检定得到技能值+1。
```

**示例**（额外行动）：
```
⚡在你回合期间，花费2资源：你本回合可以进行额外1次行动。(每回合仅限一次)
```

### 使用次数

```
使用(N类型)。
```

**示例**：
```
使用(2子弹)。
使用(1充能)。
使用(2资源)。每轮开始时重新补满资源。
使用(充能数等于你控制卡牌的职阶数，包含本卡牌)。
```

补充写法：`补满` 或 `重新补满`。

### 永久卡

```
永久。
[被动效果描述]
```

**示例**（苦心钻研）：
```
永久。
每场游戏开始时，你的起始手牌中额外有一张卡牌。
```

## 六、数据字段速查

**每种卡牌类型的完整字段说明和模板，见 SKILL.md 的「卡牌类型完整参考」章节。** 这里只补充字段类型的注意事项。

### 字符串型 vs 数字型（重要）

以下字段在 JSON 里是**字符串型**（不是数字），因为可能含特殊值：

| 字段 | 适用 | 字符串取值 |
|---|---|---|
| `shroud` | 地点卡 | `"2"`、`"?"`、`"X"` |
| `clues` | 地点卡 | `"2"`、`"0"`、`"2<调查员>"`（按调查员数缩放） |
| `attack` | 敌人卡 | `"3"`、`"X"`、`"?"` |
| `evade` | 敌人卡 | `"4"`、`"X"`、`"?"` |
| `enemy_health` | 敌人卡 | `"6"`、`"X"`、`"?"`、`"6<调查员>"`（按调查员数缩放） |
| `threshold` | 场景卡/密谋卡 | `"7"`、`"3<调查员>"` |

以下字段是**数字型**：

| 字段 | 适用 | 取值 |
|---|---|---|
| `cost` | 支援卡/事件卡 | 正数=费用；`-1`=无费用；`-2`=X费用 |
| `level` | 玩家卡 | 0-5；`-1`=无等级 |
| `health` | 支援卡/调查员 | 支援卡非盟友=-1；盟友/调查员=正数 |
| `horror` | 支援卡/调查员 | 同上 |
| `enemy_damage` | 敌人卡 | 整数（生理伤害） |
| `enemy_damage_horror` | 敌人卡 | 整数（精神恐惧） |
| `victory` | 敌人/地点 | 整数或 null |

### `<调查员>` 标记（按人数缩放）

敌人生命值、地点线索值、场景/密谋阈值可能按调查员数缩放，写法是 `数字<调查员>`：
- `enemy_health: "6<调查员>"` → 6 × 调查员数
- `clues: "2<调查员>"` → 2 × 调查员数
- `threshold: "3<调查员>"` → 3 × 调查员数

### 调查员卡背 card_back 结构

调查员卡背的 `card_back` 是一个对象：
- `other`：牌库构建规则，用【】标记段落（牌库张数、构建选项、构建需求等）。
- `story`：背景故事。
- 可选 `size`：牌库张数（默认30）。

### 常见 traits 值

- 支援卡：`道具`、`武器`、`近战`、`枪械`、`工具`、`科学`、`法术`、`才能`、`仪式`、`协作`、`遗物`、`乐器`、`守护`、`祝福`、`诅咒萦绕`、`违法`、`盟友`、`天赋`
- 敌人卡：`怪物`、`类人`、`异形`、`精英`、`异教徒`、`附身`
- 诡计卡：`恐怖`、`征兆`、`险境`、`隐私`

### 常见 slots 值

`手部`、`双手`、`法术`、`双法术`、`身体`、`盟友`、`附件`、`饰品`、`塔罗`、`空`（空图标槽位）。无槽位填 `null`。
