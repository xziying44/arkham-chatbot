# 卡牌类型完整参考

每种卡牌类型的完整字段说明和 JSON 模板。**所有卡牌都有 name 和 body（body 可为空字符串），以下只列出各类型特有的字段。**

## 玩家卡（构筑卡组用的卡）

### 支援卡（资产卡：武器、工具、盟友、法术等）

```json
{
  "type": "支援卡",
  "name": "战术铲",
  "class": "生存者",
  "cost": 3,
  "level": 0,
  "traits": ["道具", "工具", "武器", "近战"],
  "slots": "手部",
  "health": -1,
  "horror": -1,
  "body": "使用(3耐久)。\n➡️花费1耐久：【攻击】。你本次检定得到+1👊。造成+1伤害。",
  "language": "zh"
}
```
- `cost`：费用数字。正数=正常费用；`-1`=无费用（永久卡/天赋）；`-2`=X 费用。
- `traits`：特性数组（**不带句号**）。常见：道具、武器、近战、枪械、工具、科学、法术、才能、仪式、协作、遗物、乐器、守护、祝福、诅咒萦绕、违法、盟友、天赋。
- `slots`：槽位。取值：`手部`、`双手`、`法术`、`双法术`、`身体`、`盟友`、`附件`、`饰品`、`塔罗`、`空`（空图标槽位）。无槽位填 `null`。如有第二槽位可加 `slots2`。
- `health`/`horror`：非盟友类支援卡填 `-1`；盟友类填正数（如 health:2, horror:2）。

### 事件卡

```json
{
  "type": "事件卡",
  "name": "心胜于物",
  "class": "探求者",
  "cost": 1,
  "level": 0,
  "traits": ["洞察"],
  "body": "快速。只能在你回合期间打出。\n直到本轮结束，你可以用你的📚代替你的👊和🦶。",
  "language": "zh"
}
```
- 字段同支援卡（cost/level/traits），但无 slots/health/horror。

### 技能卡

```json
{
  "type": "技能卡",
  "name": "推理",
  "class": "探求者",
  "level": 0,
  "traits": ["精通"],
  "submit_icon": ["智力"],
  "body": "如果调查一个地点时本技能检定成功，额外发现该地点的1个线索。",
  "language": "zh"
}
```
- `submit_icon`：**技能卡特有**。投入图标数组，元素只能是：`意志`、`智力`、`战力`、`敏捷`、`狂野`。可重复（如 `["战力","战力","狂野"]`）。简称转换：脑→意志、拳→战力、脚→敏捷、书→智力、?→狂野。
- 无 cost/slots。

### 升级卡 / 定制卡（DIY 通用卡，最灵活）

```json
{
  "type": "升级卡",
  "name": "自定义卡牌",
  "class": "守护者",
  "body": "正文内容，用规范 emoji 和【】语法写。",
  "language": "zh"
}
```
- 只有 name + body + class。升级卡正文支持 `□` 方框标记升级选项（每个选项一行，`□` 数量=XP 档位）：`□ 【选项名。】 效果描述。`

### 调查员卡（正面）

```json
{
  "type": "调查员",
  "name": "🏅\"倒霉蛋\"奥图尔",
  "class": "流浪者",
  "subtitle": "前科犯",
  "attribute": [2, 3, 3, 4],
  "health": 8,
  "horror": 6,
  "traits": ["罪犯"],
  "body": "⚡在你回合期间，花费2资源：你本回合可以进行额外1次行动。(每回合仅限一次)\n⭐效果：+2。如果你成功，获得2资源。",
  "language": "zh"
}
```
- `subtitle`：副标题（调查员的职业/身份描述）。
- `attribute`：**四维数组** `[意志, 智识, 战斗, 敏捷]`，每个 1-5 的整数。如 `[2,3,3,4]`。
- `health`/`horror`：调查员的生理伤害/精神恐惧承受上限（正数）。
- `body`：调查员能力。常用 `⚡`（反应能力）+ `⭐效果：+N。附加效果`（技能投入时的加成）。
- 独特调查员 name 前可加 `🏅`。

### 调查员卡背

```json
{
  "type": "调查员卡背",
  "name": "🏅佐伊·萨马拉斯",
  "class": "守护者",
  "subtitle": "主厨",
  "card_back": {
    "other": "【牌库卡牌张数：】30。\n【牌库构建选项：】守护者卡牌(🛡️)等级0-5，中立卡牌等级0-5，所有其他职阶的卡牌(🔍、🚶、🧘和/或🏕️)等级0最多5张。\n【牌库构建需求】(不计入卡牌张数)：佐伊的十字架、击退邪恶、1张随机基础弱点。",
    "story": "调查员的背景故事..."
  },
  "language": "zh"
}
```
- `class`：**必须和正面调查员的 class 一致**（如正面是守护者，卡背也填守护者）。漏填会使用中立卡框，导致正背面职阶不一致。
- `card_back`：**调查员卡背特有**的对象，包含：
  - `other`：牌库构建规则。用【】标记每段：`【牌库卡牌张数：】30。`、`【牌库构建选项：】...`、`【牌库构建需求】(不计入卡牌张数)：...`。额外规则用 `【额外冒险设置：】`。
  - `story`：调查员背景故事（风味文字）。
- name 通常和正面调查员同名。

## 遭遇卡（剧本里的卡）

### 敌人卡

```json
{
  "type": "敌人卡",
  "name": "🏅塞拉斯·毕晓普",
  "class": "遭遇",
  "traits": ["怪物", "异形", "精英"],
  "enemy_damage": 2,
  "enemy_damage_horror": 2,
  "attack": "3",
  "evade": "7",
  "enemy_health": "6<调查员>",
  "victory": 2,
  "body": "庞大。\n塞拉斯·毕晓普不能进行趁乱攻击。",
  "language": "zh"
}
```
- `class`：遭遇卡填 `"遭遇"`。
- `enemy_damage`：敌人造成的生理伤害（整数）。
- `enemy_damage_horror`：敌人造成的精神恐惧（整数）。
- `attack`：攻击值（**字符串型**），如 `"3"`、`"X"`、`"?"`。
- `evade`：躲避值（**字符串型**）。
- `enemy_health`：敌人生命值（**字符串型**）。可为数字字符串 `"6"`，或 `"X"`、`"?"`，或按调查员数缩放 `"6<调查员>"`（表示6×调查员数）。
- `victory`：胜利点数（整数或 null）。

### 地点卡

```json
{
  "type": "地点卡",
  "name": "走廊",
  "location_type": "已揭示",
  "traits": [],
  "shroud": "1",
  "clues": "0<调查员>",
  "location_icon": "红方",
  "location_link": ["蓝三角", "红十", "绿菱"],
  "victory": null,
  "body": "",
  "language": "zh"
}
```
- `location_type`：**必填**。`已揭示` 或 `未揭示`。
- `shroud`：险峻值（**字符串型**）。**仅已揭示面填**，如 `"2"`、`"?"`、`"X"`。未揭示面不填。
- `clues`：线索值（**字符串型**）。**仅已揭示面填**。可为 `"2"` 或按调查员数缩放 `"2<调查员>"`。
- `location_icon`：地点图标标识。取值：`绿菱`、`暗红漏斗`、`橙心`、`浅褐水滴`、`深紫星`、`深绿斜二`、`深蓝T`、`紫月`、`红十`、`红方`、`蓝三角`、`褐扭`、`青花`、`黄圆`。
- `location_link`：连接的地点图标数组（元素同上）。
- 未揭示面地点卡：`location_type: "未揭示"`，不填 shroud/clues。

### 诡计卡

```json
{
  "type": "诡计卡",
  "name": "引起怀疑",
  "class": "遭遇",
  "traits": [],
  "body": "【显现】 - 在你所在地点的每个{罪犯}敌人上放置1个毁灭标记。如果未因本效果放置毁灭标记，失去2资源。",
  "language": "zh"
}
```
- `class`：填 `"遭遇"`（遭遇诡计）或 `"弱点"`（玩家弱点诡计）。
- `body`：通常以 `【显现】 - 效果` 开头。

### 场景卡（Act）

```json
{
  "type": "场景卡",
  "name": "被困于此",
  "serial_number": "1a",
  "threshold": "2<调查员>",
  "body": "",
  "language": "zh"
}
```
- `serial_number`：场景编号（如 `"1a"`、`"2b"`）。字母 a=正面，b=背面。**制作背面（b 面）用单独的 `场景卡背` 类型**（见下节）。
- `threshold`：推进阈值（**字符串型**），如 `"3<调查员>"`（3×调查员数的线索）或 `"7"`。

### 密谋卡（Agenda）

```json
{
  "type": "密谋卡",
  "name": "食尸鬼崛起",
  "serial_number": "2a",
  "threshold": "7",
  "body": "",
  "language": "zh"
}
```
- `serial_number`：密谋编号（如 `"1a"`、`"2b"`）。**制作背面（b 面）用单独的 `密谋卡背` 类型**（见下节）。
- `threshold`：毁灭推进阈值（**字符串型**），如 `"7"`。

### 场景卡背 / 密谋卡背（Act/Agenda 背面，1b、2b 等）

```json
{
  "type": "场景卡背",
  "name": "深入调查",
  "serial_number": "1b",
  "victory": null,
  "body": "（翻面后的正文效果...）",
  "flavor": "可选风味文字",
  "language": "zh"
}
```
- `type`：`场景卡背`（Act 背面）或 `密谋卡背`（Agenda 背面）。**不要**用 `type: "场景卡"` + `is_back: true`（校验器不认 `is_back` 字段）。
- `serial_number`：编号用 `b` 结尾（如 `"1b"`、`"2b"`），与对应正面（`1a`）成对。
- 无 `threshold`（背面不填推进阈值）。
- `victory`：背面可给胜利点数（整数或 null）。

### 故事卡

```json
{
  "type": "故事卡",
  "name": "故事标题",
  "body": "故事正文...",
  "language": "zh"
}
```
- 只有 name + body。

## 通用字段说明

| 字段 | 类型 | 适用 | 说明 |
|---|---|---|---|
| `type` | string | 所有 | 卡牌类型（见上方各类型） |
| `name` | string | 所有 | 卡牌标题 |
| `class` | string | 玩家卡/遭遇卡 | 职阶：守护者/探求者/流浪者/潜修者/生存者/中立/多职阶/遭遇/弱点 |
| `subclass` | string[] | 多职阶卡 | 当 class="多职阶"时，填包含的职阶（最多2个） |
| `cost` | number | 支援卡/事件卡 | 费用。正数=费用；-1=无费用；-2=X 费用 |
| `level` | number | 玩家卡 | 等级 0-5。-1=无等级 |
| `traits` | string[] | 大多数 | 特性数组（不带句号） |
| `body` | string | 所有 | 效果正文（emoji+【】语法） |
| `flavor` | string? | 可选 | 风味文字（背景故事/台词） |
| `language` | string | 所有 | `zh`（中文）、`en`、`zh-CHT` |
