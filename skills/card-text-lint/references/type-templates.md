## 8. 各卡牌类型的常用句模速查

本章按卡牌类型给出最高频的句模模板，写某类卡时直接套用。

### 8.1 玩家事件卡 / 技能卡

- **打出时机**：`快速。只能在你回合期间打出。` / `快速。在<触发时机>时打出。`
- **额外费用**：`作为打出<卡牌名>的额外费用，<费用>。`（技能卡用 `作为将<卡牌名>投入技能检定的额外费用，<费用>。`）
- **技能卡首行限制**：`每次技能检定最多投入1张。` / `只能投入你正在执行的技能检定。`
- **基础行动增强**：`将<卡牌名>在基础攻击行动期间投入时，其获得👊👊和以下文本：“<效果>。”`
- **打出前置条件**：`你未与敌人交战时才能打出。` / `仅当你至少拥有1个线索才可打出。`
- **每轮限制**：`每轮最多2张{抉择}。`

### 8.2 玩家支援卡

- **计数器声明**：`使用(3补给)。如果急救没有补给，将其弃掉。`
- **常驻加成**：`你得到+1📚。` / `{条件}时，你得到+1📚。`
- **行动能力**：`➡️：【攻击】。你本次攻击得到+2👊。本次攻击造成+1伤害。`
- **免费行动**：`⚡横置看门狗：与你所在地点的一个敌人交战。`
- **反应能力**：`⭕你击败一个敌人后：在本卡牌上放置1个资源(从供应堆拿取)，作为证据。`
- **强制能力**：`【强制】 - 当神话阶段结束时：你必须花费1资源或弃掉黑暗仪式。`
- **检定**：`检定🧠或📚(4)。` / `检定🧠(X)，其中X为附魔护甲上的伤害与恐惧总值。`
- **附属**：`将手铐附属到该敌人。`
- **封印**：`封印(最多5🌑)。`
- **入场/离场**：`⭕在职业枪手入场后：…` / `【强制】 - 在潜水服离场时：将其从游戏中移除。`

### 8.3 敌人卡

- **关键词堆叠**：`猎手。` / `警戒。隐匿1🕵️。猎手。反击。`
- **【猎物】**：`【猎物】 - 仅对承受者。` / `【猎物】 - 🦶最低。` / `【猎物】 - 手牌最少。`
- **【生成】**：`【生成】 - 任意无人地点。` / `【生成】 - 最近的{荒地}地点。` / `【生成】 - 与你所在地点👊最低的调查员交战。`
- **【显现】**：`【显现】 - 将乔伊斯·小利透放置入场，放到小利透书店，带有1🕵️个线索。` / `【显现】 - 秘密地将本敌人加入你的手牌。`
- **【强制】**：`【强制】 - 当敌军阶段结束时：在混乱袋中加入1个🌑标记。` / `【强制】 - 在银暮秘社僧侣攻击后：在当前密谋上放置1个毁灭标记。`
- **检定**：`➡️：【谈判】。检定🧠(3)。` / `➡️：检定🧠(X)，其中X为哈斯塔的攻击值。`
- **数值加成**：`猩红野兽位于{节点地}地点时得到+2攻击值和-2躲避值。` / `虚空的奇美拉得到+1🕵️生命值。`
- **击败与处决**：`【强制】 - 在恶毒邪灵因(除{法术}或{遗物}以外的)伤害而被击败时：不将其弃掉，改为治愈其所有伤害，将其横置。` / `➡️花费2个线索：【谈判】。将彼得·沃伦加入胜利区。`
- **直接伤害/恐惧**：`本敌人攻击造成的伤害/恐惧将视为直接伤害/恐惧。`
- **交战/躲避/攻击**：`在你躲避兜帽人后：其攻击你。` / `其本次攻击造成+2伤害。`

### 8.4 地点卡

- **检定**：`➡️：【谈判】。检定👊(4)以加入游戏。` / `检定📚+🦶(9)来触碰喷泉中心的火盆。`
- **行动关键词**：`➡️：【调查】。` / `➡️：【移动】。从水下洞窟移动到任意淹没的{洞穴}地点。` / `➡️：【撤退】。` / `➡️：【阵法】。检定🧠+👊(11)来清理出树林的一条通路。`
- **强制能力**：`【强制】 - 当一轮结束时：位于月兽之城每位调查员检定🦶(2)。` / `【强制】 - 在非{精英}敌人进入本地点时：对它造成1点伤害。`
- **线索**：`➡️：检定🧠或🦶(4)。如果你检定成功，发现本地点的1个线索。` / `【强制】 - 如果伦敦雨街没有线索：在上面增加线索，直到其有1🕵️个线索。`
- **隐藏值**：`伦敦雨街得到+X隐藏值。X为当前场景编号。` / `场上每有一个{动荡}钥匙，藏钥馆得到+2隐藏值。`
- **连接**：`神秘阶梯与其上方和下方的地点连接。` / `宏伟入口与每个{洞穴}地点相连接，反之亦然。` / `东城区与维尔玛小餐馆相互连接。`
- **进入限制**：`你不能进入本地点，除非你控制了蓝色钥匙。` / `作为你进入本地点的额外费用，你所在地点的调查员必须共同花费4🕵️个线索。`
- **地点机制行**：`隐匿1。` / `掩藏。` / `道路1。` / `幻景2🕵️(狩猎失败之记忆)。` / `【目标】 - 如果每位没有被击败的调查员都在猎鹰岬通路，推进。` / `【显现】 - 将新格林教堂放置入场。`
- **揭示/揭露**：`⚡花费3资源：【谈判】。揭露任意地点一张隐匿迷你卡牌。(团队每轮仅限一次。)` / `查看本地点X张隐匿迷你卡牌的已揭示面<i>(不将其揭露)</i>。`

### 8.5 诡计卡

- **【显现】**：`【显现】 - 将海妖之唤放置入场，放到你的威胁区域。` / `【显现】 - 在混乱袋中加入5个🌑标记。` / `【显现】 - 弃掉你全部资源。`
- **涌动**：`如果场上没有{同志会}敌人，溜之大吉获得涌动。否则，找到最近的{同志会}敌人并检定🦶(3)。`
- **玩家选择项**：`你必须(选择以下一项)：<点> 受到1点直接伤害并承受1点肉体创伤。<点> 受到1点直接恐惧并承受1点精神创伤。`
- **检定失败按差值**：`你检定失败且每低于难度1点，受到1点恐惧。` / `如果你检定失败且低于难度至少3点，改为失去2个行动。`
- **混沌标记**：`在混乱袋中加入1个🌑标记。检定🧠(4)。` / `从混乱袋中揭示5个混乱标记。每揭示一个💀或🐙标记，受到1点伤害和1点恐惧。`
- **自动失败**：`如果你本次技能检定期间揭示了👹标记，你自动失败。`
- **威胁区域弱化牌**：`麻木可被治愈，如同是你身上的1点恐惧<i>(如果它被治愈，将其弃掉)</i>。` / `你得到-1🧠和-1神智。`
- **清理型弱点收尾**：`➡️➡️：弃掉噩梦来袭。`

### 8.6 密谋卡 / 场景卡

- **【强制】**：`【强制】 - 在本密谋推进时：将上面所有的毁灭标记移动到下一个密谋。` / `【强制】 - 当敌军阶段结束时：对月下餐厅的调查员造成总计X点伤害，自由分配。X为阴影中敌人的数量。`
- **【目标】推进**：`【目标】 - 如果朱三娘被击败，推进。` / `【目标】 - 只有伦敦塔的调查员可以共同花费所需数量的线索以推进。` / `【目标】 - 如果所有未被击败的调查员都撤退，推进。`
- **推进句式**：`将密谋直接推进到密谋3a<i>(不结算密谋2b)</i>。` / `在密谋2a上放置4个毁灭标记。推进场景。` / `本效果能导致本密谋推进。`
- **毁灭标记/阈值**：`*本密谋得到+1🕵️毁灭阈值。` / `【强制】 - 如果本密谋将要因为毁灭达到阈值而推进：每位调查员被击败并承受1点精神创伤。`
- **结局跳转**：`【(→结局1)】<i> (第31页)</i>` / `<点> 如果戴红手套的男子和艾里奇·佐尼·奥佩勒曲亚都在胜利区，进入【(→结局1)】<i>(第57页)</i>。`
- **场景设置/清理**：`将放在一边的塔桥和伦敦塔地点放置入场。` / `将遭遇弃牌堆和放在一边的X洗入遭遇牌库。` / `每位调查员失去其所有线索。`
- **授予能力**：`每个带有恐惧的地点获得：“【强制】 - 在你离开本地点后：检定🦶(4)。如果你检定失败，受到1点恐惧和1点伤害。”`
- **剧本日志**：`在剧本日志中，记录<i>X</i>。` / `在剧本日志中，记一点【确信】。` / `检查剧本日志。`
- **提示**：`<i>(提示：在本密谋推进时，如果未发现朱三娘所在地点，她会收割附近的魂灵！)</i>` / `(注意：不位于该处的所有调查员将会阵亡。)`
- **撤退/败北**：`每位没有撤退的调查员被击败并承受1点肉体创伤。` / `➡️：【撤退】。`

### 8.7 调查员卡 / 特殊卡

- **起始设置**：`你以达雷尔的柯达相机在场上开始游戏。` / `你开始游戏时把索菲<i>(深切的思念)</i>放置入场。` / `你以磁通量稳定器在场上开始游戏，<i>(关闭)</i>面朝上。`
- **额外行动**：`在你回合期间，你可以进行额外一次行动，该行动只能用于下方的➡️能力。` / `你可以在自己回合期间进行额外一个行动，该行动只能用于躲避。`
- **密钥卡【变换】**：`【变换】 - 对你所在地点的一个敌人造成2点伤害，或对你所在地点的每个敌人造成1点伤害。将本钥匙翻至{动荡}面。` / `【变换】 - 治愈场上每个敌人1点伤害。然后，如果是调查员变换了本钥匙，将其翻至{稳定}面。`
- **混沌袋操作**：`冒险设置期间，在混乱袋中加入2个🌟标记。` / `将你揭示的💀标记的修正值视为"0"。` / `用下列标记单独创建一个袋子：💀、📜、📜、📜、📜、👤、👤。`
- **故事卡**：`【如果调查员拥有少于3🕵️个线索：】` 后接 `<flavor quote="true" padding="20" …>叙事</flavor>`，指令用裸句。
- **批量结算**：`位于[地点]的每位调查员[治愈/受到/取得/承受]X点…` / `每位调查员取得2点奖励经验值。`
