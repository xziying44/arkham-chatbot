## 7. 资源·线索·伤害·标记等量词

量词是 DIY 卡牌文本里最容易一眼暴露「非官方」的细节。官方对每一类对象都有**固定的量词**与**固定的动词**，两者必须成套出现。

### 7.1 量词对照总表（先背这张表）

| 对象 | 规范量词 | 规范动词搭配 |
|---|---|---|
| 资源 | **不加量词** | 获得 / 花费 / 失去 X资源 |
| 线索 | **个**（常带 🕵️：1🕵️个线索） | 发现 / 花费 / 放置 / 增加…直到 |
| 伤害 / 恐惧 | **点** | 受到 / 造成 / 治愈 / 承受 X点 |
| 直接伤害 / 直接恐惧 | **点** | 视为 / 作为直接伤害(恐惧) |
| 精神创伤 / 肉体创伤 | **点** | **承受**（不用「受到」） |
| 毁灭标记 | **个** | 放置 X个毁灭标记 |
| 秘密 / 充能 / 补给 / 子弹 / 贡品 / 证据 / 钥匙 / 车票 / 次数 / 灵脉 / 锁头 | **个**（计数声明用「使用(N…)」，简洁句可省略） | 花费 X个 / 每有 X |
| 混沌标记（🌑⭐🌟💀👤📜👹🐙❄） | **个** | 加入 / 移除 / 揭示 X个+符号+标记 |
| 行动 | **个 / 次**（官方两种都存在） | 花费 / 失去 X个行动 |
| 奖励经验值 | **点** | 取得 X点奖励经验值 |
| 平民 | **个** | 解救 / 遭到杀害 X个平民 |

### 7.2 资源：官方从不写「个」

资源是唯一一种**不加量词**的对象，数值直接跟在动词后面。正文本体**不会**出现「1个资源」「X点资源」。

- ✅ `获得1资源。`
- ✅ `花费2资源。`
- ✅ `失去1资源。`
- ✅ `将你资源池的最多3资源移动到暗红骑士。`（连「资源池」里的资源也不加量词）
- ❌ `获得1个资源。`
- ❌ `获得2 个 资源。`（不仅多加「个」，数值与量词间也不允许空格）

「资源池」是官方术语，指的是你面前的那堆资源，写作用「资源池」，不要写成「资源堆」。

### 7.3 线索：X个线索，量词用「个」；按人数缩放的数量才带 🕵️

线索是卡牌标记（「线索标记」），量词一律用「个」。**普通线索数量（发现、花费、放置单个线索）不带 🕵️**；只有「随调查员人数缩放」的数量（团队共同费用、线索阈值、敌方自带的人均线索等）才在数字旁标注 🕵️。

- ✅ `发现本地点的1个线索。`
- ✅ `花费4🕵️个线索。`
- ✅ `调查员共同花费1🕵️个线索。`
- ✅ `如果伦敦雨街没有线索：在上面增加线索，直到其有1🕵️个线索。`（补足用「增加…直到…」）
- ✅ `将本地点1个线索移动到最近的{异教徒}敌人上。`（搬动用「移动」）
- ✅ `你每有一个线索，本次攻击造成+1伤害(最多+3伤害)。`（条件量词用「每有一个」）
- ❌ `获得你所在地点的1个线索。`（从地点上拿线索用「发现」；「从供应堆获得1个线索」才是官方写法，两种动词别混）
- ❌ `线索+1` / `增加1线索` / `发现线索*2`（都不规范，应为「发现1个线索」「放置1个线索」）

注意 🕵️ 的两种含义不要搞混：跟在线索数字后是「按人数缩放」标注（`调查员共同花费1🕵️个线索`）；跟在敌人生命值数字后表示「每位调查员」（`得到+1🕵️生命值` = 每人+1生命）。

### 7.4 伤害与恐惧：X点

伤害与恐惧用「点」，动词用「受到」「造成」「治愈」，句式是「受到X点伤害」或「造成+X伤害」。

- ✅ `受到1点伤害和1点恐惧。`
- ✅ `本次攻击造成+1伤害。`
- ✅ `治愈2点伤害，或2点恐惧，或1点伤害和1点恐惧。`
- ✅ `每位调查员受到X点伤害和X点恐惧。`
- ❌ `造成1伤害`（漏「点」）
- ❌ `本次攻击造成伤害+1`（官方固定句式是「造成+1伤害」，加成量在「+X」里）

攻击附加的伤害量写成「本次攻击造成+X伤害」，不写「本次攻击伤害+X」「增加2伤害」。「每有一个线索，本次攻击造成+1伤害(最多+3伤害)」这种带条件的加成，条件放句首。

### 7.5 直接伤害 / 直接恐惧：规则术语，用「视为/作为」

「直接伤害」「直接恐惧」是**规则术语**，表示越过伤害分配流程直接扣血。官方用「视为直接伤害」或「作为直接伤害/直接恐惧」引出，量词仍是「点」。

- ✅ `本敌人攻击造成的伤害/恐惧将视为直接伤害/恐惧。`
- ✅ `对其所在地点的每位调查员造成其伤害和恐惧，作为直接伤害/直接恐惧。`
- ✅ `每位调查员受到1点直接伤害。`
- ❌ `不分配伤害`（口语，官方不这么写）
- ❌ `造成真实伤害`（「真实伤害」不是官方词）

### 7.6 精神创伤与肉体创伤：动词是「承受」，不是「受到」

创伤是伤害之外的一套系统，动词**必须用「承受」**，量词用「点」。正文本体不会出现「生命值」「神智值」这类字段词。

- ✅ `佐伊·萨马拉斯承受1点精神创伤。`
- ✅ `每位没有撤退的调查员被击败并承受1点肉体创伤。`
- ✅ `受到1点直接伤害并承受1点肉体创伤。`（伤害=受到，创伤=承受，同句内也要严格区分）
- ❌ `受到1点精神创伤。`
- ❌ `获得1点肉体创伤。`

「被击败并承受X点肉体创伤」是败北结算的固定连动句式，主语常是「每位没有撤退的调查员」「幸存的每位调查员」，不要简化成「阵亡」（「阵亡」是另一个规则概念）。

### 7.7 各类计数器标记：秘密 / 充能 / 补给 / 子弹 / 贡品 / 证据 / 钥匙 / 车票 / 次数 / 灵脉 / 锁头

计数器在卡面顶部以「使用(N计数器名)」紧凑声明，**名字直接写进括号**；正文引用时用「个」，官方在简洁句里也常省略量词。

- ✅ `使用(3补给)。使用(4秘密)。使用(6子弹)。`
- ✅ `如果急救没有补给，将其弃掉。`（耗尽离场用固定句模「如果{卡名}没有{计数器名}，将其弃掉。」）
- ✅ `花费1秘密：选择任意一个未附属到{精英}敌人的非弱点诡计。`
- ✅ `花费1充能：改为揭示2个混乱标记，而非1个。`
- ✅ `显微镜上每有1证据，你本次调查得到+1📚(最多+3📚)。`
- ❌ `3点耐久度，耗尽后弃掉`（「耐久度」是**卡牌字段/关键词**，不是正文计数器名；应改写为「使用(3补给)。如果急救没有补给，将其弃掉。」）
- ❌ `消耗1耐久度攻击`（「消耗」+「耐久度」的混搭在官方语料中不存在）

特殊资源（如**以太**）与资源同理不加「个」：`花费1以太`。

### 7.8 毁灭标记与其他标记

毁灭标记用「个」，动词是「放置」；混沌袋中的标记符号用「数量+符号+标记」的顺序。

- ✅ `在当前密谋上放置1个毁灭标记。`
- ✅ `在密谋2a上放置4个毁灭标记。`
- ✅ `在混乱袋中加入2个🌑标记。`
- ✅ `从混乱袋中揭示5个混乱标记。每揭示一个💀或🐙标记，受到1点伤害和1点恐惧。`
- ✅ `查找混乱袋，找出一个⭐标记，将其封印在清算之日上。`
- ❌ `加一个毁灭`（漏「标记」二字）
- ❌ `毁灭点数` / `黑暗标记`（都是口语，官方统一「毁灭标记」）

各类标记有**专用术语**，不要笼统写「放个标记」：毁灭标记、枯竭标记、深度标记、研究标记、屏障、空洞。数量写「X个+符号+标记」，「2个🌟标记」不是「🌟×2」；多符号并列时符号写在列表里（次级袋如「蛛群滋生袋」用「💀、📜、📜、👤」列出）。

### 7.9 花费的规范表达

「花费」的对象按类型严格搭配量词，团队支付必须写「共同花费」。

- ✅ 花费资源：`花费2资源。`
- ✅ 花费线索：`花费4🕵️个线索。` / `花费1个线索：解救你所在地点的一个平民。`
- ✅ 花费计数器：`花费1秘密：…` / `花费1充能：…`
- ✅ 花费行动：`作为打出精益求精的额外费用，花费一个行动。`
- ✅ 团队共同支付：`塔桥的调查员必须共同花费2🕵️个线索。` / `只有位于伦敦塔的调查员可以共同花费所需数量的线索以推进。`

「作为打出X的额外费用」是额外费用的固定前缀（事件卡用「打出」，技能卡用「投入技能检定」），费用内容以「花费/加入/受到/弃掉」等动词开头。费用数字与动词之间不加空格。

### 7.10 获得 / 发现 / 失去 / 取得——动词与对象一一对应

- **资源 → 获得**：`获得1资源。` ❌ 不能说「发现1资源」。
- **线索 → 发现**：`发现你所在地点的1个线索。` 从供应堆获取线索用「获得」：`从供应堆获得1个线索。` 两种动词按来源区分，不可互换。
- **行动 → 失去**：`失去1个行动。` / `如果你检定失败且低于难度至少3点，改为失去2个行动。`
- **奖励经验值 → 取得**：`每位调查员取得2点奖励经验值。`
- **伤害/恐惧 → 治愈**：`治愈1点伤害。`

### 7.11 数值加减：降低 / 减少 / 得到负值

数值变化按对象选择不同动词，且符号必须**紧贴数值**（`+1👊`，不写 `+1 👊`）：

- 难度 → **降低** X点 / 得到难度-X / 难度+X：
  - ✅ `所附属地点的所有技能检定难度降低1点。`
  - ✅ `你可以花费1个线索以将本次检定难度降低2点。`
  - ✅ `该检定得到难度-2。`
  - ✅ `本次检定难度+1🕵️。`
- 隐藏值 → X隐藏值 / 隐藏值-X：
  - ✅ `你所在地点的隐藏值-1，直到本回合结束。`
  - ✅ `伦敦雨街得到+X隐藏值。X为当前场景编号。`
- 技能值/攻击值等 → 得到+X图标 / 技能值+X / 值-X：
  - ✅ `你得到-1🧠和-1神智。`
  - ✅ `你在{工具}支援的技能检定期间得到技能值+1。`
- 手牌上限 → **减少** X张：
  - ✅ `你的手牌上限减少X张。`

官方用「降低」表达难度下降，「减少」用于手牌上限等数量。不要写「攻击力+1」（技能用图标+数值，属性用「技能值+1」式）；「难度」的变化不要写成「减少1点难度」。

### 7.12 每点缩放效果里的量词

按超过/低于难度每点缩放时，量词写法是「你检定成功且每超过难度1点，…」/「你检定失败且每低于难度1点，…」，每步效果的对象量词照常使用。

- ✅ `你检定成功且每超过难度1点，获得1资源(最多6)。`
- ✅ `你检定成功且每超过难度1点，获得1资源(最多3个)。`
- ✅ `你检定失败且每低于难度1点，受到1点恐惧。`

上限一律用**全角括号**写在句末（`(最多6)` / `(最多3个)` / `(最多+3伤害)`），不写「上限3个」这类口语。
