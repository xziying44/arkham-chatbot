## 1. 导读与目标

### 这份文档是给谁看的？

给想自己 DIY 诡镇奇谭卡牌、但担心写得不像官方出品的小白。你可以在这里查到**每一种卡面写法的标准格式**：检定怎么写、能力前缀怎么选、关键词怎么堆、量词怎么配、混沌标记怎么用符号表示。

### 文档约定

- **✅ 正确写法**：直接取自官方简体中文语料，照抄即可。
- **❌ 错误写法**：小白 DIY 时的高频误写，一律避开。
- 所有示例用代码块标注，符号（图标、括号、冒号）都是语法的一部分，**不是装饰**，请逐字符核对。

### 新手最常见的四大误区（先记住）

| 小白写法 | 官方写法 | 一句话原因 |
|---|---|---|
| `➡️横置：进行1次 🧠(4)检定…` | `➡️：检定🧠(3)。如果你检定成功，弃掉印斯茅斯面容。` | 「➡️」已隐含横置；检定是「检定+图标(难度)」 |
| `装备后获得+1 👊` | `你得到+1👊。` | 官方无「装备后」；加号紧贴图标无空格 |
| `➡️ 启动：消耗1耐久度攻击…` | `➡️花费1充能：【攻击】。你本次攻击得到+1👊。` | 普通卡无「启动」引导（「启动」仅载具卡行动关键词）；无「耐久度消耗」 |
| `3点耐久度，耗尽后弃掉` | `使用(3补给)。如果急救没有补给，将其弃掉。` | 「耐久度」是字段词，不进正文 |

这四个错误在第 9 章有完整对照解析。

## 9. 常见错误对照表

> 本章是全文档的「兜底检查清单」。所有「✅正确写法」均直接取自官方简体中文语料；所有「❌错误写法」是小白 DIY 时的高频误写。对照原则只有一条：**官方说什么你就写什么，官方语料里不存在的格式一律不写。**

**使用方法（写卡四步自查）**
1. 先通读 9.3「易错点清单」，避开最高频雷区；
2. 对照 9.1「四个高频典型错误」，确认自己没有踩同款；
3. 按 9.2 的分主题对照表逐条检查正文句式；
4. 把草稿读出声，凡读到「进行…检定」「装备后」「➡️启动：」「消耗耐久度」「耗尽后弃掉」「免费行动：」等口语词，立即标记改写。

### 9.1 四个高频典型错误（必须纠正的示例）

| # | ❌ 错误写法 | ✅ 正确写法 | 为什么错 |
|---|---|---|---|
| 1 | `➡️横置：进行1次 🧠(4)检定，成功就对交战敌人造成1点伤害` | `➡️：检定🧠(3)。如果你检定成功，弃掉印斯茅斯面容。` | ①「➡️」本身已隐含「横置调查员并花费一个行动」，正文再写「横置」重复（官方只有横置对象**不是调查员**时才显式写「➡️横置{支援}：…」）；②「进行1次…检定」是口语，官方一律「检定图标(难度)」且动词前置、图标与括号难度直接相连无空格；③「成功就…」不是官方句式，结果分支用「如果你检定成功，…」；④「🧠(4)」接在「检定」之后才是正确顺序，「🧠(4)检定」这种把图标放前面的写法也是错的。 |
| 2 | `装备后获得+1 👊` | `你得到+1👊。`；条件版：`你资源池没有资源时，你得到+1🧠、+1📚、+1👊和+1🦶。` | ①官方没有「装备后」这个用语，常驻/条件加成用完整句式「你得到+X图标」；②加号必须紧贴图标，`+1 👊`带空格、`+1`与`👊`之间不得有空格；③「获得」用词也不对，官方加成动词是「得到」。 |
| 3 | `➡️ 启动：消耗1耐久度攻击，本次攻击再+1 👊` | `➡️花费1充能：【攻击】。你本次攻击得到+1👊。`（无消耗版：`➡️：【攻击】。你本次攻击得到+1👊。`） | ①普通卡不用「启动」引导行动，行动前缀就是「➡️」（「启动」只是载具卡专用行动关键词）；②「消耗1耐久度」是混搭错误——「耐久度」是卡牌字段词，计数器类消耗写「花费N充能/子弹/秘密」；③句末「再+1 👊」不成句，加成要用「你本次攻击得到+X图标」，且图标紧贴数值无空格。 |
| 4 | `3点耐久度，耗尽后弃掉` | `使用(3补给)。如果急救没有补给，将其弃掉。` | ①「耐久度」是卡牌字段/关键词，不应混进正文句子里；②计数器用「使用(N计数器名)」紧凑声明，名字写进括号（子弹/秘密/充能/补给等）；③耗尽时的离场处理用固定句模「如果X没有计数器名，将其弃掉。」，「耗尽后弃掉」不是官方表述。 |

### 9.2 分主题错误对照总表

#### 9.2.1 能力前缀与能力结构

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `➡️横置：…` / `➡️启动：…` | `➡️：…`；横置对象不是调查员时写 `➡️横置{支援}：…` | 「➡️」已隐含行动语义，普通卡不用「启动」引导行动（「启动」只是载具卡专用行动关键词）；横置调查员无需写出，横置支援才显式写 |
| `免费行动：…` | `⚡：…`（如 `⚡横置看门狗：与你所在地点的一个敌人交战。`） | 免费行动能力用「⚡」前缀表达，不写「免费行动：」前缀（但「免费打出X」是官方合法短语，「免费」一词不禁用） |
| `强制：当一轮结束时…` | `【强制】 - 当一轮结束时：…` | 「【强制】」后用「 - 」连接再写条件，小白常漏掉破折号与括号 |
| `显现时：…` / `当显现…` | `【显现】 - 将X放置入场，放到你的威胁区域。` | 显现没有触发条件，直接接效果，「显现时」是口语 |
| `获得反应能力：当你横置X后…` | `⭕在你横置X后：…` | 「⭕」的触发条件必须放冒号前，小白把条件误放效果侧 |
| `【强制】 - 效果：条件`（条件效果写反） | `【强制】 - 条件：效果` | 三段式固定：中括号关键词＋「 - 」＋触发条件（冒号前）＋效果（冒号后） |
| `需要两个行动` | `➡️➡️：…` | 双行动是两个箭头连写，不写「需要两个行动」 |

#### 9.2.2 检定句式

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `进行1次 🧠(4)检定` | `检定🧠(4)` | 官方动词前置、无「进行1次」 |
| `🧠(4)检定` / `检定(4)🧠` | `检定🧠(4)` | 图标紧贴「检定」，难度在图标后的括号里 |
| `检定难度为4` | `检定🧠(4)` | 难度是括号里的数字，不写「难度4」 |
| `检定 🦶 (3)`（带空格） | `检定🦶(3)` | 现行规范图标与括号直接相连无空格 |
| `检定🧠/📚(4)`、`检定🧠、📚(4)` | `检定🧠或📚(4)` | 多技能并列用「或」，不用「/」或顿号 |
| `改为用🧠检定` | `本次攻击不使用👊，改为使用🧠。` | 官方固定镜像句式「不使用…，改为使用…」 |
| `超出难度` / `没超过难度` | `超过难度` / `低于难度` / `等于难度` | 「超过/低于/等于难度」是固定搭配 |
| `成功2点以上` / `检定大成功` | `如果你检定成功且超过难度至少2点，…` | 官方只认门槛式「超过难度至少X点」 |
| `每多1点` / `每失败1点` | `你检定成功且每超过难度1点，获得1资源(最多6)。` / `你检定失败且每低于难度1点，受到1点恐惧。` | 「每超过/低于难度1点」是官方固定量词结构 |
| 「至少」与「正好」混用 | 按需选用：`超过难度至少X点` ≠ `超过难度正好2点` | 两个句式官方并存但语义不同，至少=门槛、正好=精确 |
| `检定必然失败` | `如果你本次技能检定期间揭示了👹标记，你自动失败。` / `本次检定自动成功。` | 「自动成功/自动失败」是固定短语；「必然失败」是口语，对应失败句式是「你本次技能检定期间揭示了👹标记，你自动失败」 |

#### 9.2.3 数值加成与词序

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `+1 👊`（带空格） | `+1👊`（无空格） | 加号必须紧贴数值/图标 |
| `攻击力+1` | `你得到+1👊`；属性加成写 `技能值+1`、`难度-2` | 词序是「得到+X图标」或「属性+数值」，不写「攻击力+1」 |
| `装备后获得+1👊` | `你得到+1👊`；条件加成写 `{条件}时，你得到+1…` | 官方没有「装备后」 |
| `增加2伤害` | `本次攻击造成+2伤害` | 攻击修饰量用「+X」且放「造成」前 |
| `线索+1` / `增加1线索` | `发现1个线索`；消耗写 `花费1个线索`；调查改写写 `不发现线索，改为…` | 线索用「发现/花费/放置」动词 |
| `🌟×2` | `在混乱袋中加入2个🌟标记` | 顺序是「数量+符号+标记」 |
| `你得到-1🧠和-1生命值`（技能/生命值图标混用） | 技能用图标、神智/生命值用文字：`你得到-1🧠和-1神智。` | 官方区分：技能=图标，神智/生命值=文字 |
| 把 `得到+1🕵️生命值` 的🕵️误读为调查技能 | 正确理解为「每位调查员」（即每人+1生命值） | 🕵️在此表示「每位调查员」，极易误读 |
| `隐匿值+X` / `隐蔽值` | `{地点}得到+X隐藏值` | 以「隐藏值」为准（个别官方卡译作「隐蔽值」，属翻译不一致） |

#### 9.2.4 计数器、消耗与「耐久度」

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `3点耐久度，耗尽后弃掉` | `使用(3补给)。如果急救没有补给，将其弃掉。` | 耐久度是字段词；计数器用「使用(N计数器名)」声明 |
| `消耗1耐久度攻击` | `➡️花费1充能：【攻击】。…` | 耐久度不参与消耗，用计数器名「花费N子弹/秘密/充能」 |
| `加一个毁灭` | `在其上放置1个毁灭标记` | 毁灭标记用「放置」动词 |
| `放个标记`（笼统） | 专用标记名：`毁灭标记`/`枯竭标记`/`深度标记`/`研究标记`/`屏障`/`空洞` | 标记类型是专用术语，不笼统写 |
| `骷髅标记`（文字） | `💀`（符号） | 混沌标记一律用符号，多个并列用顿号 |

#### 9.2.5 打出 / 进入 / 投入的条件句

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `装备后…`（条件不完整） | `你未与敌人交战时才能打出。` / `仅当你至少拥有1个线索才可打出。` | 条件句一律以「才能/才可/只能」收尾 |
| `需要钥匙才能进去` | `你不能进入本地点，除非你控制了蓝色钥匙。` | 官方用「不能…除非…」结构 |
| 团队费用只写「花费」 | `作为你进入本地点的额外费用，你所在地点的调查员必须共同花费4🕵️个线索。` | 团队支付必须写「共同花费」，「额外费用」四字不可省 |
| `普通攻击` | `基础攻击行动` / `基础调查行动` / `基础躲避行动` | 官方术语是「基础XX行动」 |
| `每回合最多打两张` | `每轮最多2张{抉择}。` | 「每轮最多X张{抉择}」是官方专有格式，{抉择}表示玩家有选择权 |

#### 9.2.6 量词与动词搭配

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `受到1点精神创伤` | `承受1点精神创伤` | 创伤动词是「承受」而非「受到」 |
| `获得1个资源` | `获得1资源` | 资源不加量词 |
| `失去1行动` / `失去1点行动` | `失去1个行动` | 行动用「个」 |
| `混沌袋` | `混乱袋`（`在混乱袋中加入1个🌑标记`） | 官方用「混乱袋」 |
| `造成X点恐惧` 误用于受害者侧 | 受方写 `受到X点恐惧`，施方写 `对其造成X点伤害/恐惧` | 主动被动动词对应 |

#### 9.2.7 术语与状态词

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| `进场` / `下场` | `入场` / `离场` | 官方只有「入场/离场」两个术语 |
| `装备到该卡` | `将X附属到Y` | 「附属」是动词不是名词 |
| `胜利牌堆` | `将其加入胜利区` | 固定叫「胜利区」 |
| `阵亡` 与 `被击败` 混用 | 区分使用 | 两个不同规则概念 |
| `不分配伤害` | `视为直接伤害` / `作为直接伤害` | 「直接伤害/直接恐惧」是规则术语 |
| `放在一边` 与 `从游戏中移除` 混用 | 场外预留= `放在一边，位于场外`；永久移除= `从游戏中移除` | 两种不同状态，不可混用 |
| `正面` / `翻开那一面` | `已揭示面`（`查看…的已揭示面<i>(不将其揭露)</i>`） | 「揭示/揭露」两套动词体系，小白常混用 |
| `翻成` / `翻转` | `将本钥匙翻至{动荡}面。` / `然后，如果是调查员变换了本钥匙，将其翻至{稳定}面。` | 翻面动词固定用「翻至…面」，朝面用{稳定}/{动荡}键接表示 |
| `活着的调查员` | `未被击败的调查员` | 官方统一用「未被击败」 |
| `当作提醒` | `将本卡牌放在场景牌库旁作为提示` | 提醒标记用「放在…旁作为提示」 |
| `启动：…` / `使用` / `探索一下` | `➡️：…` / `【谈判】` / `【移动】` / `【探索】` | 普通卡行动关键词必须原样使用，不自创（「启动」是载具卡专用行动关键词，普通卡不用） |
| `消灭` / `击杀`（敌人处理） | `将其加入胜利区` / `不将其弃掉，改为治愈其所有伤害，将其横置。` | 击败后的处理是固定短语 |
| `从牌库拉出来放到地点上` | 地点/剧情卡写 `将X放置入场，放到Y，带有Z`；敌人写 `生成在X` | 「放置入场」与「生成」区分 |
| `记一分` / `记1次` | `在剧本日志中，记一点【确信】。`；记录条目用斜体：`记录<i>达贡已苏醒</i>` | 计数值用「记一点【…】」，条目名用斜体 |
| `小提示：` | `(提示：….)`（如 `<i>(提示：…)</i>`） | 「提示」是策略提醒，不是规则指令 |
| `完成场景目标` | `推进` / `推进场景` / `推进本密谋` | 官方一律用「推进」 |

#### 9.2.8 频率限制与括注

| ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|---|---|
| 把限制写进句首当条件 | `(每轮仅限一次。)` 作句末括号附注 | 限制语是句末括注，不参与正文句子 |
| `每回合只能一次`（混用粒度） | 按粒度选：`(每轮仅限一次。)`、`(每次检定仅限一次。)`、`(每场游戏仅限一次。)` | 「每轮/每回合/每次检定/每场游戏」各有专用词，不可混写 |
| 漏写「团队」主语 | `(团队每轮仅限一次。)` | 「团队」前缀代表全队合计一次 |
| `只能用一次` | `仅限一次` | 「仅限」是固定搭配 |
| 数量带图标写错 | `1🕵次` | `1🕵️次` | 数量带图标时图标紧贴数字，且 🕵 统一带变体选择符写作 `🕵️` |

### 9.3 易错点：新手最常犯的错误清单

按踩坑频率从高到低：

1. **检定句口语化**——「进行1次🧠(4)检定」「🧠(4)检定」「检定(4)🧠」「检定难度为4」全部错误，唯一正确格式是 `检定图标(难度)`（多技能用「或」）。
2. **能力前缀误用**——「➡️」后加「横置/启动」重复；「免费行动：」应写「⚡：」；「【强制】」漏「 - 」连接符；「⭕」的触发条件必须放冒号前。
3. **触发条件与效果写反**——「【强制】/⭕」类能力，条件永远在冒号前、效果在冒号后。
4. **数值加成空格与词序**——`+1 👊`、`装备后获得`、`攻击力+1`、`增加2伤害`、`线索+1` 都不是官方写法。
5. **「耐久度」与计数器混淆**——「3点耐久度，耗尽后弃掉」应为「使用(3补给)。如果…没有补给，将其弃掉。」；「消耗1耐久度攻击」应为「花费N充能/子弹/秘密」。
6. **量词系统错乱**——创伤用「承受」不是「受到」；资源不加量词；混沌标记用符号不用文字（「骷髅标记」✗）；毁灭标记用「放置」。
7. **状态词与术语**——入场/离场、揭示/揭露、阵亡/被击败、「放在一边，位于场外」vs「从游戏中移除」、「翻至…面」都是易混点。
8. **频率限制**——时间粒度专用词（每轮/每回合/每次检定/每场游戏）、句末括号附注、「团队」主语三者缺一不可。
9. **检定结果分级混淆**——门槛式「超过难度至少X点」与逐点式「每超过难度1点」是两个不同句式，不可混用；「至少」与「正好」不可互换。
10. **关键词改写口语化**——{抉择}、{特性}、封印(…)、附属、蜂拥X、猎手、基础攻击行动等官方术语必须原样使用，不口语化改写。
11. **回合阶段名写错**——简中官方译名：神话阶段 / 调查阶段 / 敌军阶段 / **补给阶段**（不是"维持阶段"）。一轮≠一回合（轮=完整一圈含所有阶段，回合=单个玩家的行动回合）。

## 10. DIY 自查清单

写完一张卡面，按以下清单逐条核对。全部通过，才算「像官方出品」。

**第一关：符号自查（对应第 3 章）**
- [ ] 检定格式是 `检定图标(难度)`，没有「进行1次」「检定难度为4」「图标倒装」。
- [ ] 图标与数字零空格：`+1👊`、`技能值+1`、`难度-2`，没有 `+1 👊`。
- [ ] `➡️` 后没有重复「横置」；普通卡没有用「启动」引导行动。
- [ ] 混沌标记全部用符号（🌑⭐🌟💀👤📜👹🐙❄），没有写「骷髅标记」「混沌袋」。
- [ ] 🕵️ 的位置正确：`调查员共同花费1🕵️个线索`=每人，`🕵(3)`=调查技能；普通线索数（`发现1个线索`）不加 🕵️。
- [ ] 键接术语都加了花括号：{精英}、{法术}、{抉择}、{稳定}、{动荡}。
- [ ] 难度/数值变量写了定义句：`其中X为…` / `X等于…` / `X为…`。

**第二关：能力前缀自查（对应第 4 章）**
- [ ] 每一条能力都选对了前缀：`➡️` / `⚡` / `⭕` / `【强制】` / `【显现】`。
- [ ] 触发条件与费用都在全角冒号 `：` 前，效果在冒号后。
- [ ] `【强制】` 是「【强制】 - 条件：效果」三件套，没有漏「 - 」和 `【】`。
- [ ] `【显现】` 后没有「显现时」「当显现」。
- [ ] 行动代称后面是句号不是冒号：`【调查】。`。
- [ ] 双行动写 `➡️➡️`，没有写「需要两个行动」。
- [ ] 多个费用用「并」连接，费用与冒号之间无空格。

**第三关：关键词自查（对应第 6 章）**
- [ ] 关键词都句号独立成句，堆叠用句号分隔：`猎手。警戒。`，没有顿号/空格堆叠。
- [ ] 「快速」是 `快速。` + 第二句给时机，没有「快速行动：」。
- [ ] 计数器用「使用(N计数器名)」，没有「耐久度」进正文。
- [ ] 「附属」作动词用：「将X附属到Y」，没有「装备到该卡」。
- [ ] 封印上限写在 `封印(最多N{符号})` 括号内。
- [ ] 「每轮最多2张{抉择}。」是专有格式，没有口语化改写。
- [ ] 不限量用「任意数量」，没有自创「无限」关键词。

**第四关：量词自查（对应第 7 章）**
- [ ] 资源不加「个」：`获得1资源`。
- [ ] 线索量词用「个」：`发现1个线索`；按人数缩放的数量才带 🕵️（`调查员共同花费1🕵️个线索`）。
- [ ] 创伤动词是「承受」：`承受1点精神创伤`，没有「受到1点精神创伤」。
- [ ] 团队费用写「共同花费」。
- [ ] 混沌标记顺序是「数量+符号+标记」：`2个🌟标记`，不是 `🌟×2`。
- [ ] 加成伤害写「本次攻击造成+X伤害」，没有「攻击力+1」。

**第五关：结果句自查（对应第 5 章）**
- [ ] 成败分支用「如果你检定成功/失败，…」，没有「如果成功的话」「检定通过时」。
- [ ] 门槛用「超过难度至少X点」，逐点用「每超过/低于难度1点」，二者没有串。
- [ ] 「自动成功/自动失败」是固定短语；揭示特定混沌标记导致的失败用「你本次技能检定期间揭示了{符号}标记，你自动失败」句式。
- [ ] 目标 → 检定 → 成功/失败分支的顺序没有打乱。
- [ ] 上限用全角括号写在句末：`(最多6)` / `(最多+3伤害)`。

**第六关：标点自查（对应 3.8）**
- [ ] 冒号全部全角 `：`。
- [ ] 频率附注是句末圆括号独立成句：`(每轮仅限一次。)`。
- [ ] 分项列表用 `<点> ` 前缀（含空格）。
- [ ] 斜体用 `<i>…</i>`，页码写法如 `<i> (第31页)</i>`（空格有无并存）。

> 读出声测试：把草稿朗读一遍，凡读到「进行…检定」「装备后」「➡️启动：」「消耗耐久度」「耗尽后弃掉」「免费行动：」「混沌袋」「骷髅标记」「攻击力+1」等词，立即标记改写。
