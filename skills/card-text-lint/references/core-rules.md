## 2. 总则：官方语言风格

写任何卡面之前，先建立三条总体意识：

1. **官方说什么你写什么，官方语料里不存在的格式一律不写。**
   - 普通卡正文没有「发动」「使用能力」「进行技能检定」「装备后」「消耗耐久度」「耗尽后弃掉」这类动词引导写法（「启动」只是载具卡专用行动关键词，见 3.2）。行动能力就是 `➡️`，免费行动就是 `⚡`，反应就是 `⭕`。
2. **符号本身就是语法。** 技能图标、混沌标记、行动前缀、花括号 `{…}`、斜体 `<i>…</i>`、全角冒号 `：`、圆括号 `(…)` 都不是装饰，写错位置就变味。
3. **先选前缀，再套句式。** 写任何能力前先问三个问题：
   - 这是什么能力类型？（选对前缀：`➡️` / `⚡` / `⭕` / `【强制】` / `【显现】`）
   - 有触发条件或费用吗？（全部放在全角冒号 `：` **之前**）
   - 效果是什么？（放在冒号**之后**）

> 一条铁律贯穿全文：**触发条件与费用永远在冒号前，效果永远在冒号后。** 这是新手错误率最高的位置问题。
