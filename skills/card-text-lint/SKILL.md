# 诡镇奇谈卡牌正文语法校准

> **🚨 最高优先级护栏：判断要不要校准的唯一标准——用户写的是不是大白话。**
> - 是大白话（「扣血」「装上去后」「用3次坏了」「每回合只能一次」）→ 校准成规范语法。
> - 用了任何规范术语（「检定」「补给阶段」「横置」「弃掉」「抽取」「反应」「快速」等）→ **保持原样，绝不改写**。
> 你（LLM）的语法记忆可能过时，用户写的可能本来就是对的。**擅自「修正」用户已规范的术语 = 把对的改成错的 = 事故。**

当用户用大白话描述卡牌效果时，你需要将其翻译成**官方规范的卡牌正文**。全部规范来自官方卡牌真实语料（`.card` 文件的 `body` 字段）。**官方语料中不存在的格式，一律不要写。**

## 何时使用此技能

当 diy-card 技能的工作流进行到 Step 2（写 .card 文件）时：
- 先按上面的「唯一标准」判断用户正文是不是大白话。
- 是大白话 → 读此技能的参考文档，翻译成规范语法，写入 .card。
- 不是大白话（已用规范术语）→ **跳过本技能**，用户原文照搬进 .card。

### 绝对不要做的事

- ❌ 用户写「补给阶段开始时」，你改成「维持阶段开始时」，还告诉用户「帮你改成了标准术语」——这是把对的改成错的。
- ❌ 用户写「检定🧠(4)」，你觉得「可以更简洁」改成「🧠检定(4)」——官方语料里就是「检定{图标}(难度)」，你在制造错误。
- ❌ 拿不准时直接改——拿不准就**保持原样**，或用 send_message 问用户。

✅ 正确做法：用户用了规范术语 → 原样；用户用了大白话 → 校准；拿不准 → 保持原样或问。

## 卡牌语言速记

### 图标词表

| 类型 | 符号 | 说明 |
|---|---|---|
| 技能 | 🧠意志 👊战斗 🦶敏捷 📚学识 🕵调查 | 用于检定与加成 |
| 万能技能 | ❓ | 检定写「检定任意技能(难度)」；描述卡牌**获得**图标才写「获得❓❓」 |
| 行动前缀 | ➡️ | 行动能力，**已隐含"横置调查员、消耗1行动"** |
| 免费行动 | ⚡ | 免费行动能力，不写「免费行动：」前缀。⚡ 仅用于"你可以主动选择触发的免费行动" |
| 反应 | ⭕ | **反应能力**，触发条件在冒号前。当效果描述含「在…后」「当…时」「每当…」等被动触发条件时，**必须用 ⭕ 而非 ⚡** |
| 段前缀 | 【强制】/【显现】/【猎物】/【生成】 | 方括号关键词 + ` - ` + 内容 |
| 混沌标记 | 🌑⭐🌟💀👤📜👹🐙❄ | 一律用符号，不写文字名 |
| 键接术语 | `{精英}` `{法术}` `{抉择}` `{稳定}` | 可检索的类型/特性必须用花括号 |

### 核心句式

- **检定**：`检定{图标}(难度)`，如 `检定📚(4)`、`检定🧠或📚(8)`
- **常驻加成**：`你得到+1👊`（不写「装备后」）
- **本次加成**：`你本次攻击得到+2👊`；`本次攻击造成+1伤害`
- **成功/失败**：`如果你检定成功，…` / `如果你检定失败，…`
- **能力结构**：`➡️[费用]：【行动关键词】。效果`；`【强制】 - 条件：效果`；`【显现】 - 效果`
- **多行动能力**：消耗多个行动 = 多个 ➡️ 连写（`➡️➡️` 双行动、`➡️➡️➡️` 三行动，中间无空格）。**行动数量只用图标表达，绝不写「花费N行动」文字**——那是资源/计数器费用的写法。详见下方「⚠️ 行动 vs 资源」辨析。
- **使用次数**：`使用(N类型)。`（如 `使用(3耐久)。`）
- **限制**：`(每回合仅限一次)` 用圆括号
- **选择列表**：`(选择一项)：` / `(选择以下一项)：` / `(选择一项或多项)：` 后，每个选项用 **`<点> ` 前缀（含空格）、各占一行**。用户用 `- `/`~ `/`* `/`•` 开头的列表项**必须转成 `<点> `**（详见下方「⚠️ 选择列表」）。

### 常见大白话→规范语法对照

| 用户说的（不标准） | 规范写法 | 说明 |
|---|---|---|
| 「装上去后获得+1拳」 | `你得到+1👊。` | 不写「装备后」，常驻加成直接写 |
| 「攻击消耗耐久度」 | `使用(N耐久)。➡️花费1耐久：【攻击】。效果` | 用「使用」声明耐久，「花费」消耗 |
| 「用3次就坏了，弃掉」 | `当此卡上没有耐久时，弃掉此卡。` | 不写「坏了」，用「弃掉」 |
| 「进行一次战斗检定」 | `检定👊(难度)` | 不写「进行…检定」 |
| 「扣血/掉血」 | `造成N点伤害` | 不写「扣血」 |
| 「消耗这张卡」 | `横置此卡` | 本游戏用「横置」不用「消耗」 |
| 「花费两个行动 / 花费2行动 / 需要两个行动」 | `➡️➡️：效果` | **行动数量用图标表达**：N 个行动 = N 个 ➡️ 连写（双行动 `➡️➡️`、三行动 `➡️➡️➡️`）。绝不写「花费N行动」文字——那是资源费用的写法。详见下方「⚠️ 行动 vs 资源」辨析 |
| 「每回合只能用一次」 | `(每回合仅限一次)` | 圆括号注 |
| 「- 选项」/「~ 选项」/「* 选项」/「• 选项」（列表前缀） | `<点> 选项` | 选择列表项用 `<点> ` 前缀（含空格，每项一行）；引导语用圆括号 `(选择一项)：`。详见下方「⚠️ 选择列表」 |
| 「摸牌/抽牌」 | `抽取1张卡牌` | 用「抽取」 |
| 「回血」 | `治愈N点伤害` | 用「治愈」 |
| 「在你回合结束后」「当你…后」「每当…时」 | `⭕在你的回合结束时：…` `⭕当你…后：…` | **被动触发用 ⭕ 反应图标**，不要用 ⚡ 闪电。⚡ 仅用于主动免费行动 |
| 「你可以免费做某事」 | `⚡：效果` | 主动免费行动才用 ⚡ |

### ⚠️ 行动数量 vs 资源费用（最高频混淆点）

**行动**用 ➡️ 图标数量表达；**资源/计数器**用「花费N资源/充能/子弹」文字表达。两者绝不能混：

| 用户大白话 | 正确翻译 | 为什么 |
|---|---|---|
| 花费两个行动抽4张牌 | `➡️➡️：抽取4张卡牌。` | 行动数量 → N 个 ➡️ 连写 |
| 花费2资源抽1张牌 | `➡️花费2资源：抽取1张卡牌。` | 资源 → 「花费N资源」写在冒号前 |
| 花费1充能攻击 | `➡️花费1充能：【攻击】。效果` | 计数器 → 「花费N充能」写在冒号前 |

❌ 最常见错误：把「花费两个行动」翻成 `➡️花费2行动：` —— 行动不是资源，不能写「花费N行动」文字。详细规则见 `references/abilities.md` 4.10 节。

**但**：如果用户**已经**写了 `➡️花费1行动：XXX` 这种含图标的混合写法，**绝不要改成 `➡️➡️：`**。即使两者看上去都消耗 2 行动，结算可能不同（某些卡对「花费1个行动」的触发会区分图标触发与文字触发）。**含任何规范图标/术语的正文一律保持原样**（见最高优先级护栏）——只有纯大白话（无图标、无规范结构）才翻译。

### ⚠️ 选择列表：`-` / `~` / `*` / `•` → `<点>`

用户发来的「选择一项/多项」列表，常写成 `- 选项`、`~ 选项`、`* 选项`、`• 选项` 形式。**必须转成 `<点> ` 前缀**（`<点>` 后一个空格，每项各占一行），引导语「选择…」用半角圆括号。

例（用户原话）：
> 选择一项或多项：
> ~将场上所有盟友支援卡以及非精英敌人卡移出游戏
> ~将场上所有道具支援卡以及非弱点诡计卡移出游戏
> ~将遭遇弃牌堆和调查员们的弃牌堆的所有卡移出游戏。

转成规范 body（写入 .card 的 body 字段）：
```
(选择一项或多项)：
<点> 将场上所有盟友支援卡以及非精英敌人卡移出游戏。
<点> 将场上所有道具支援卡以及非弱点诡计卡移出游戏。
<点> 将遭遇弃牌堆和调查员们的弃牌堆的所有卡移出游戏。
```

要点：`<点>` 后有**一个空格**；每项**独占一行**（body 里即 `\n`）；引导语用半角圆括号 `(选择一项)：` / `(选择以下一项)：` / `(选择一项或多项)：`。

### 校准工作流

1. **判断是否需要校准**（唯一标准：是不是大白话）：
   - 用户用的是**大白话**（如「装上去后获得+1拳」「扣血」「用3次就坏了」）→ 需要校准
   - 用户已经用了**规范术语**（「补给阶段」「检定」「横置」「弃掉」「抽取」「反应」「快速」）→ **不要加载本技能，原文照搬**
2. **读取参考文档**：需要校准时，根据卡牌类型读 `references/type-templates.md`（模板）和 `references/common-errors.md`（常见错误对照）
3. **翻译成规范文本**：按官方句式重写 body，直接写进 .card（不需要单独发消息等确认——diy-card 会一次性渲染发图，用户看到卡图后自然反馈要改哪里）
4. **歧义时才问**：如果某处不确定用户的意思（不是不确定规范写法，而是不确定用户要表达什么效果），用 send_message 问。仅因「不确定规范译名」而拿不准时，保持用户原样。
