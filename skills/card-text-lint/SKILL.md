# 诡镇奇谈卡牌正文语法校准

当用户用大白话描述卡牌效果时，你需要将其翻译成**官方规范的卡牌正文**。全部规范来自官方卡牌真实语料（`.card` 文件的 `body` 字段）。**官方语料中不存在的格式，一律不要写。**

## 何时使用此技能

当 diy-card 技能的工作流进行到 Step 2（写 .card 文件）时：
- 如果用户描述的效果**不是标准语法**（如「装上去后获得+1拳」「攻击消耗耐久度」「用3次就坏了」），**必须先读此技能的参考文档**校准文本
- 校准后，**用 send_message 把校准后的规范文本发给用户确认**（如「我帮你整理成了标准语法：使用(3耐久)。你得到+1👊。➡️花费1耐久：【攻击】… 这样可以吗？」）
- 用户确认后再写入 .card 文件

### 重要：尊重用户已有的规范写法

**如果用户已经用了看起来规范的术语（如「补给阶段」「检定」「横置」「弃掉」「抽取」等），保持原样，不要自作主张"修正"。** 你（LLM）的记忆可能过时或不准确，用户写的可能本来就是对的。只有明显的大白话（如「装上去后」「用3次就坏了」「扣血」）才需要主动校准。

对于拿不准的术语，可以**询问用户**而非直接改：
- ❌ 错误做法：用户写「补给阶段开始时」，你擅自改成「维持阶段开始时」，还告诉用户"帮你改成了标准术语"
- ✅ 正确做法：用户写「补给阶段开始时」，你觉得规范就保持原样；如果你觉得可能不规范，问用户「这里你写的是补给阶段，我查到的官方译名也是补给阶段，保持原样可以吗？」

## 卡牌语言速记

### 图标词表

| 类型 | 符号 | 说明 |
|---|---|---|
| 技能 | 🧠意志 👊战斗 🦶敏捷 📚学识 🕵调查 | 用于检定与加成 |
| 万能技能 | ❓ | 检定写「检定任意技能(难度)」；描述卡牌**获得**图标才写「获得❓❓」 |
| 行动前缀 | ➡️ | 行动能力，**已隐含"横置调查员、消耗1行动"** |
| 免费行动 | ⚡ | 免费行动能力，不写「免费行动：」前缀。⚡ 仅用于"你可以主动选择触发的免费行动" |
| 反应 | ⭕ | **反应能力**，触发条件在冒号前。当效果描述含「在…后」「当…时」「每当…」等被动触发条件时，**必须用 ⭕ 而非 ⚡** |
| 段前缀 | 【强制】/【显现】/【猎物】/【生成】 | 方括号关键词 + ` - ` + 内容 |
| 混沌标记 | 🌑⭐🌟💀👤📜👹🐙❄ | 一律用符号，不写文字名 |
| 键接术语 | `{精英}` `{法术}` `{抉择}` `{稳定}` | 可检索的类型/特性必须用花括号 |

### 核心句式

- **检定**：`检定{图标}(难度)`，如 `检定📚(4)`、`检定🧠或📚(8)`
- **常驻加成**：`你得到+1👊`（不写「装备后」）
- **本次加成**：`你本次攻击得到+2👊`；`本次攻击造成+1伤害`
- **成功/失败**：`如果你检定成功，…` / `如果你检定失败，…`
- **能力结构**：`➡️[费用]：【行动关键词】。效果`；`【强制】 - 条件：效果`；`【显现】 - 效果`
- **使用次数**：`使用(N类型)。`（如 `使用(3耐久)。`）
- **限制**：`(每回合仅限一次)` 用圆括号

### 常见大白话→规范语法对照

| 用户说的（不标准） | 规范写法 | 说明 |
|---|---|---|
| 「装上去后获得+1拳」 | `你得到+1👊。` | 不写「装备后」，常驻加成直接写 |
| 「攻击消耗耐久度」 | `使用(N耐久)。➡️花费1耐久：【攻击】。效果` | 用「使用」声明耐久，「花费」消耗 |
| 「用3次就坏了，弃掉」 | `当此卡上没有耐久时，弃掉此卡。` | 不写「坏了」，用「弃掉」 |
| 「进行一次战斗检定」 | `检定👊(难度)` | 不写「进行…检定」 |
| 「扣血/掉血」 | `造成N点伤害` | 不写「扣血」 |
| 「消耗这张卡」 | `横置此卡` | 本游戏用「横置」不用「消耗」 |
| 「每回合只能用一次」 | `(每回合仅限一次)` | 圆括号注 |
| 「摸牌/抽牌」 | `抽取1张卡牌` | 用「抽取」 |
| 「回血」 | `治愈N点伤害` | 用「治愈」 |
| 「在你回合结束后」「当你…后」「每当…时」 | `⭕在你的回合结束时：…` `⭕当你…后：…` | **被动触发用 ⭕ 反应图标**，不要用 ⚡ 闪电。⚡ 仅用于主动免费行动 |
| 「你可以免费做某事」 | `⚡：效果` | 主动免费行动才用 ⚡ |

### 校准工作流

1. **判断是否需要校准**：
   - 用户用的是**大白话**（如「装上去后获得+1拳」「扣血」「用3次就坏了」）→ 需要校准
   - 用户已经用了**看起来规范的术语**（如「补给阶段」「检定」「横置」「弃掉」「抽取」「反应」「快速」）→ **保持原样，不要改**，你的记忆可能不准确
2. **读取参考文档**：需要校准时，根据卡牌类型读 `references/type-templates.md`（模板）和 `references/common-errors.md`（常见错误对照）
3. **翻译成规范文本**：按官方句式重写 body
4. **发消息确认**：用 send_message 把整理后的文本发给用户，如：

   > 你描述的效果我帮你整理成了标准语法：
   > 使用(3补给)。
   > 你得到+1👊。
   > ➡️花费1补给：【攻击】。你本次检定得到+1👊。造成+1伤害。
   > 当此卡上没有补给时，弃掉此卡。
   >
   > 这样可以吗？确认后我就渲染卡图。

5. **等用户确认**：用户说「可以」「没问题」后再写 .card 文件。用户要改就调整后再次确认。

## 参考文档

完整语法规范在 `references/` 目录下：
- `quick-reference.md`：速查表（最常用）
- `type-templates.md`：各卡牌类型的正文模板
- `common-errors.md`：常见错误对照（大白话→规范）
- `abilities.md`：行动/反应/强制/显现能力详解
- `keywords.md`：关键词（猎手/庞大/快速/永久等）
- `icons.md`：图标完整参考
- `quantities.md`：量词与数值表达
- `core-rules.md`：核心规则术语
