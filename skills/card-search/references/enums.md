# 口语 → 数据库标准值 映射表

用户不会用数据库里的标准术语，会说俗称、简称、近义词。这张表帮你把口语翻译成 `search_cards` 的标准参数值。

## type（卡牌类型）标准值

数据库 `type` 字段的合法值（15 种）：

`调查员` `支援卡` `事件卡` `技能卡` `敌人卡` `地点卡` `诡计卡` `密谋卡` `场景卡` `故事卡` `密钥卡` `冒险参考卡` `调查员卡背` `定制卡` `场景卡-大画` `密谋卡-大画`

### 常见口语映射

| 用户说 | 标准值 |
|---|---|
| 调查员 / 角色 / 英雄 / 人物 | `调查员` |
| 装备 / 物品 / 道具卡 / 摆场上场的卡 | `支援卡` |
| 事件 / 瞬发 / 打出去就生效的 | `事件卡` |
| 技能 / 投入检定的卡 | `技能卡` |
| 敌人 / 怪物 / 怪 / 打我的 | `敌人卡` |
| 地点 / 场景地点 | `地点卡` |
| 诡计 / 弱点事件 / 威胁区 | `诡计卡` |
| 密谋 / doom 推进 | `密谋卡` |
| 场景 / 剧本进度 | `场景卡` |

⚠️ 颜色对应（官方卡牌边框色，供参考但数据库不用颜色）：
守护者=蓝、探求者=黄、流浪者=绿、潜修者=紫、生存者=红、中立=灰。用户可能说颜色，按此表换算。

## 数值字段

| 参数 | 含义 | 注意 |
|---|---|---|
| `cost_min`/`cost_max` | 费用范围 | -1 = 无费用（技能卡/弱点） |
| `level_exact` | 精确等级 | 0-5；-1 = 无等级（基础弱点） |
| `level_min`/`level_max` | 等级范围 | 与 level_exact 互斥 |
| `health_min` | 生命下限 | 敌人卡用 enemy_health，支援/调查员用 health |
| `horror_min` | 理智下限 | 同上 |
| `attack_min` | 敌人攻击力下限 | 仅敌人卡 |
| `evade_min` | 敌人闪避值下限 | 仅敌人卡 |
| `victory_min` | 胜利点下限 | 剧本卡才有 |

### 常见口语→数值映射

| 用户说 | 参数 |
|---|---|
| 便宜 / 低费 | `cost_max: 1` 或 `cost_max: 2` |
| 贵 / 高费 | `cost_min: 4` |
| 0级 / 基础 | `level_exact: 0` |
| 高级 / 顶级 | `level_min: 4` |
| 大怪 / 肉的 | `health_min: 5` |
| 攻击高的 | `attack_min: 4` |

## 开关参数

| 参数 | 作用 |
|---|---|
| `investigator_only: true` | 只查调查员 |
| `weakness_only: true` | 只查弱点卡 |

## 查不到时怎么办

1. **放宽条件**：去掉最严格的（如去掉数值范围、只留 type）
2. **换 query**：用名字的一部分、别称、英文名重试
3. **问用户**：用 ask_user 给方向选项（职业/类型），而不是开放式问
4. 别硬编不存在的值——数据库的标准值就是上面这些，口语要先映射再查
